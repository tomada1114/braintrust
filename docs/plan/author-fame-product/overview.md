# author-fame-product(人気の出る個人プロダクト探し)

個人で無料/OSS のプロダクトを出して、人気のアプリにする。何を作るかは未定で、需要を起点に候補を出している段階。
**アイデアではなく探索の記録。** 候補から選ぶのはオーナー。

## 誰の何の困りごとか

- 対象: まだ決めていない。第 1〜2 ラウンドは開発者、第 3 ラウンドは Mac のパワーユーザー一般を対象に調べた。
- 困りごと: 候補ごとに異なる。候補の一覧と根拠は `research/2026-09-mac-power-user-demand.md` の「5. アイデア候補」と「7. 追補」、開発者向けの候補は `research/2026-09-devtool-demand.md`。

## 実在する痛みか

候補ごとに、出典で確認できた事実【確認済】、サブエージェント報告のまま【報告】、推測【推測】を分けて調査ノートに記録している。
需要の票が無い「穴」も、オーナーの方針で推測として候補に入れてある(候補 2・3・10 など)。

## 既存プロダクトとの違い

- 既存: Mac の操作効率化領域の地図(区分ごとの主要プロダクト、勢い、不満、Apple に潰されるリスク)は調査ノートの「1. 領域の地図」。
- 差分: 当たる型は 4 つ見えている。OS に欠けている 1 機能を埋める / 止まった・信頼を失った人気ツールの後継 / メーカー純正ソフトの置き換え / OS が消した・壊した挙動を戻す。空いた席は数か月で埋まる。

## 何を作るか(現時点の像)

- 形態: macOS アプリ(メニューバー常駐を含む)か CLI。Swift ネイティブ。
- 中核の体験: 未定。2026-09-20 時点の上位候補は次のとおり(人気を軸にした順)。
  1. 無料 OSS のタスクバー型 Dock(候補 14)
  2. Finder のコマンドパレット / Finder の欠落埋め(候補 5)
  3. メーカー純正ソフトの置き換え(候補 4)
  4. OSS のキーボードナビゲーション(候補 1。オーナーの好みには最も合うが、天井は 3〜4k★ 級と見ている)
- AI の位置づけ: 第 3 ラウンドでは「AI と無関係」を前提にした。次に検討する英語学習者向けでは未定。
