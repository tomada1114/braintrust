# 横断まとめ: 発信を主軸にしない個人開発で、英語圏・月10〜30万に届く分野はどこか

- 調査日: 2026-09-19
- 調査手段: Sonnet サブエージェント 3 体（さらに各自が分野別に再委譲、計 10 体超）+ メインセッションによる原典確認（Apple ガイドライン、Chromium Extensions 公式アナウンス、VS Code Publisher Agreement PDF、Shopify 公式ドキュメント、Indie Hackers / Founder Club の本人記事）
- 問い: 個人開発・英語圏・スマホアプリ除外・ゲーム/規制領域/受託除外・目標 $700〜$2,000 MRR という条件下で、賭けるに値する分野はどこか。
- 前提となるオーナーの回答（2026-09-19 のヒアリング）: ①記事執筆・X・Instagram は労力が軽いので積極的にやってよい（毎日でも可）②自分が当事者でない業界にも入る、調べて埋める ③課金は自前 Stripe に貯めて後でまとめて現金化するイメージ

## 結論

**1. 「ストアに置くだけ」では届かない。届いている実例の入口は、例外なく「ストア内検索」か「取引意図のロングテール検索」のどちらかを、作り込んだ結果として持っている。**

純粋な非発信（ストア内検索のみ、記事もSNSもなし）で目標帯に到達したと明確に言える事例は、今回の調査全体を通して BudgetSheet（$1,600 MRR）1 件だった。ただし後述する観測バイアスがあり、これを「可能性が低い」の証拠として使いすぎてはいけない。

**2. オーナーが記事執筆を許容したことで、本命が入れ替わった。**

最も稼いでいる 2 件（Closet Tools 年商 $756,500、Bank Statement Converter $38K MRR）はどちらも**取引意図の強いロングテール記事**を入口にしている。"Poshmark automation"、"HSBC statement converter" のようなクエリで、**AI Overviews に食われにくい**（ユーザーは知識ではなく処理を求めているので、AI が答えて終われない）。このリポジトリの既存調査 `english-saas-venture/research/acquisition-channels.md` は「SEO は期待値が下がった」と結論しているが、あれが測っていたのは英語学習という**情報意図**のクエリであり、**取引意図のクエリには当てはまらない**。区別が必要。

**3. 分野選定の軸は「業種」ではなく「問題の種類」にある。**

業種特化ニッチ（美容室・ジム・不動産管理・トラック運送・教会・葬儀）を調べた結果、確認できた事例はほぼ全件が**業界当事者による創業**だった（SalonScale=元サロンオーナー、RigBooks=親がトラック運送業、Farmbrite=農家夫婦、PT Distinction=パーソナルトレーナー）。一方、Bank Statement Converter の Angus Cheng は銀行事務の当事者ではない。この差は業種ではなく問題の種類にある。

- **フォーマット／データの問題**（PDF を Excel にする、A と B を同期する、形式を変換する）— 業界知識が要らない。正しさの基準が客観的で、レビューを読めば埋まる。**部外者が入れる。**
- **業務フローの問題**（予約を管理する、顧客台帳を回す、配車する）— 「何が正しい運用か」が業界の暗黙知に埋まっている。**部外者は入れない。**

オーナーは「調べて埋める」と答えたが、**埋められるのは前者だけ**、というのが今回の調査から読み取れる線である。

**4. 課金は「自前 Stripe か否か」より「入金を自分で握れるか」で見るべきだった。**

Shopify は Billing API 必須だが手数料は最初の $100 万まで 0%（Stripe の 2.9% + 30¢ より安い）。VS Code は手数料 0% で自前 Stripe 必須。つまり「自前 Stripe = 得」ではない。オーナーの「システム内に貯めて数年後に現金化」という構想に効くのは手数料ではなく**入金スケジュールの支配権**であり、この観点では Shopify は不利、Chrome 拡張 / VS Code / Workspace は有利。

## グレーゾーン・未確認

- **観測バイアスが結論を歪めている可能性が高い。** 業種特化ニッチの調査担当が指摘した通り、月 $700〜$2,000 規模で安定している事業者は、外に発信する動機もチャネルも持たないため**そもそも観測できない**。公開されている事例が「急成長して買収された」か「ほぼゼロ」の二極に偏るのはこのため。**「目標帯の事例が少ない = 目標帯に到達しにくい」とは言えない。**
- **収益額はほぼ全件が自己申告**。第三者検証（決済データの外部監査）がある事例は今回 1 件も見つからなかった。GetLatka 系の数字は同社自身が「推定値、本人インタビュー未実施」と明記している。
- **全サブエージェントが WebSearch のセッション上限（200回）に到達した。** 特に Amazon / eBay / Etsy セラー向けツール、WooCommerce、Slack、Zapier、Atlassian、Salesforce、WordPress.org は十分に調べられていない。**これらに事例が「ない」とは言えず、調査未達である。**
- **reddit.com への直接アクセスが全エージェントでブロックされた。** 収益報告スレッドの一次確認ができておらず、二次言及に依存している。
- **Shopify アプリの「オーガニックのみ」という証言の検証ができていない。** WideBundle / DropCommerce の AMA は 2021 年 12 月のもので、当時と現在ではストア内の競争環境が違う可能性がある。Shopify App Store の現在の新規アプリ発見性は未確認。
- **記事執筆の実労力を見積もっていない。** Closet Tools は「数百のロングテールキーワード」で上位を取ったとされるが、何記事書いたか、何ヶ月かかったかの一次情報は取れていない。オーナーは「記事執筆は労力が軽い」と述べているが、この規模を前提にした見積もりではない。
- **X / Instagram の投稿が効いた実例は、今回ひとつも確認できなかった。** 効いたと言えるのは Superpower ChatGPT（35万人ニュースレター＋r/OpenAI バイラル）だけで、これはオーディエンス主導の別ゲーム。オーナーは SNS 投稿も許容すると答えたが、**B2B ツールでこれが効いた証拠は今回の調査には無い。**

## 影響する論点

- どの面に賭けるか（Shopify か、独立 Web + SEO か）。この 2 つは入金の支配権と入口の作り方が正反対で、両立しない。
- 「調べて埋める」が通用するのはフォーマット／データの問題に限る、という線をオーナーが受け入れるかどうか。
- 記事執筆の実労力の見積もり。これが「軽い」のか「数百本を数ヶ月」なのかで、順位 2 の現実味が変わる。

## 訂正（2026-09-19、同日中）

**上記「結論 3」の「フォーマット／データの問題なら部外者が入れる」という主張は、根拠が誤っていた。** オーナーからの指摘（特定事例に偏りすぎていないか）を受けて原典を確認した結果、根拠として挙げた 2 件はどちらも当事者起点だった。

- **Bank Statement Converter**: Angus Cheng は自分の支出を分析しようとして、銀行が PDF しか出さないことに詰まり、自分用にスクリプトを書いた。その後**自分の会計士に処理方法を尋ね、PDF から Excel へのコピペをしていることを知り**、会計士の友人たちにも聞いて全員が同じだと確認してから SaaS 化した（2021年4月に友人に持ちかけ、翌日から開発、4月下旬に MVP）。/ URL: https://medium.com/bank-statement-converter/why-i-created-bank-statement-converter-71a413828261 , https://founderreports.com/interview/bank-statement-converter/ , https://www.starterstory.com/stories/bankstatementconverter / 出典日付: 記載なし / 確度: 中（本人記事だが、メインセッションが読んだのは検索エンジン経由の要約であり Medium 原文は未取得）
- **Closet Tools**: Jordan O'Connor の**妻**が Poshmark で販売を始め、シェア作業に長時間を費やしているのを横で見て、妻のためにスクリプトを書いた。無料でブログに公開 → 1年後に Poshmark の subreddit に投稿 → ベータテスター 200 人 → 初月 $300 MRR。/ URL: https://softwaresocial.dev/episodes/jordan-oconnor-founder-of-closet-tools , https://www.indiehackers.com/podcast/187-jordan-oconnor-of-closet-tools , https://www.swipefiles.com/everything-is-marketing/38 / 出典日付: 記載なし / 確度: 中（複数の独立した出典が一致。ただし音声コンテンツの本文は未確認、検索要約経由）

したがって「部外者が調べて埋められる」の実証例は **n=0** であり、順位 2 位に付けた推奨は取り下げる。

**さらに、Bank Statement Converter の収益額は出典間で約 12 倍ばらついている**: $38K MRR（superframeworks, 2023-10-06）、$16K/月（Founder Reports）、$12.5K MRR（Starter Story）、$12K/月（asiatomorrow.net）、$11K/月（goodreads 転載）、$3K/月（Medium / Rohidas Gowda）。時点の差だけでは説明しきれない幅であり、**上限側の数字はコンテンツファーム記事による誇張の可能性がある**。確度: 低。この 1 件を根拠に分野を選ぶべきではない。

### 訂正後に残る、最も強い発見

収益に到達した事例を起点で並べ直すと、**例外なく「本人または至近距離の他人（配偶者・親）の反復作業」から始まっている**。

| プロダクト | 起点 |
|---|---|
| Bank Statement Converter | 自分の支出 → 自分の会計士に尋ねた |
| Closet Tools | 妻の Poshmark 作業を横で観察 |
| BudgetSheet | 自分の家計管理 |
| Cronitor | 妻の DB バックアップ cron が 2 ヶ月無言で失敗していた |
| Healthchecks.io | 自分の cron |
| Gymdesk | 自分がブラジリアン柔術の実践者 |
| RigBooks | 親が 25 年以上トラック運送業 |
| Farmbrite | 自分たちの農場 |
| SalonScale | 自分がサロンオーナー |
| Easy Folders / Sync2Sheets | 自分がそのツールのユーザー |

**「分野を市場性で選び、業界知識を調べて埋めた」という起点の事例は、今回の調査全体で 1 件も見つからなかった。** 独立した出典 10 件以上で一致しており、これが本調査で最も再現性のある発見である。

Angus Cheng の経路を分解すると 2 段階になっている: ①自分の小さな痛み（自分の支出を分析したい。これ単体では商売にならない）→ ②**その痛みを職業として大量に抱えている人に直接聞く**（会計士）。②が市場を見つけた段階であり、デスクリサーチではなく会話である。

### 影響

- 分野・面の順位表よりも、「オーナーの周囲に、退屈な反復作業を毎週している実在の人間がいるか」のほうが先に効く論点である。過去 4 アイデア（すべて英語学習、うち 2 本は実装後に却下）は①で止まっており、②に相当する接触が起きていない。
- 2026-09-19 のヒアリングでオーナーが選んだ「入れる。調べて埋める（推奨）」は、**当方が提示した選択肢の説明文が誤った事実に基づいていた**ため、選択の前提が崩れている。再確認が必要。
