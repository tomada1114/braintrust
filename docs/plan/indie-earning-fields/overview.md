# indie-earning-fields

個人開発で、発信・集客をメインにせずに稼げる分野を探した調査。**アイデアではなく、分野探索そのものの記録。**
結論は「分野選びの前に、身近で反復作業をしている実在の人間を見つけるほうが先」で、
**何を作るかは決めていない。**

## この検討の位置づけ

`docs/plan/_templates/overview.md` はアイデア 1 件を書く書式だが、このディレクトリが
扱ったのは「どの分野に賭けるか」という一段手前の問いなので、書式は部分的にしか使っていない。
`english-saas-venture`（語学分野に限定した同種の検討）のメタ検討版にあたる。

## オーナーの条件（2026-09-19 のヒアリングで確定）

- 目標: 月 10〜30 万円の継続収入（≒ $700〜$2,000 MRR）
- 市場: 英語圏・グローバル
- 発信・集客をメインにしない。入口は「既存ストアの検索流入」と「検索（SEO）」
- スマホアプリ（App Store / Google Play）は避ける — 個人開発として飽和気味、かつ入金を自分で制御できない
- 除外: ゲーム / 規制の重い領域（医療・金融・士業）/ 受託・請負・時間単価型
- 課金は自前 Stripe 等に貯めて、数年後にまとめて現金化するイメージ（リスクは承知の上）
- AI の組み込みは必須条件ではない
- 追加（同日、調査途中の確認）: 記事執筆・X・Instagram への投稿は労力が軽いので積極的にやってよい

## 結論として残った学び

**収益に到達した個人開発の事例は、例外なく「本人または至近距離の他人（配偶者・親）の反復作業」から始まっていた。**
10 件以上を独立した出典で確認し、例外が 1 件もなかった。

| プロダクト | 起点 |
|---|---|
| Bank Statement Converter | 自分の支出分析 → **自分の会計士に処理方法を尋ねた** |
| Closet Tools | **妻**の Poshmark シェア作業を横で観察 |
| BudgetSheet | 自分の家計管理 |
| Cronitor | **妻の DB バックアップ cron** が 2 ヶ月間、無言で失敗していた |
| Healthchecks.io | 自分の cron |
| Gymdesk | 自分がブラジリアン柔術の実践者 |
| RigBooks | **親が 25 年以上トラック運送業** |
| Farmbrite | 自分たちの農場 |
| SalonScale | 自分がサロンオーナー |
| Easy Folders / Sync2Sheets | 自分がそのツールのユーザー |

逆に、**「儲かりそうな分野を市場性で選び、業界知識は後から調べて埋めた」という起点の事例は 1 件も見つからなかった。**

Bank Statement Converter の経路は 2 段階に分解できる。①自分の小さな痛み（自分の支出を分析したい。
これ単体では商売にならない）→ ②**その痛みを職業として大量に抱えている人に直接聞く**（会計士）。
②が市場を見つけた段階であり、デスクリサーチではなく会話である。

## この学びが過去のアイデアに対して言っていること

英語学習系 4 本（`english-saas-venture` / `english-opinion-trainer` / `small-talk-trainer` / `english-vocab-app`、
うち 2 本は実装まで進んで却下）は、いずれも①で止まっていた可能性が高い。
**痛みを感じていたのがオーナー 1 人で、②に相当する接触が起きていない。**
ただしこれは本調査から読み取れる示唆であり、過去 4 本の却下理由として記録されているものとは別である。

## ストア・分野についての副次的な発見

分野選びは本題ではなくなったが、調べた事実自体は残る。将来「何を作るか」が決まったときに効く。

- **「実績ゼロの新規参入者が検索流入だけで見つけてもらえる」ことを裏付ける定量データは、どのプラットフォームにも存在しなかった。** HubSpot は 30 日以内に 3 インストール必須、Discord は 100 サーバー未満で公式 Discovery の対象外、といった構造的な関門が規約レベルで確認された
- 課金の自由度: **自前 Stripe が可能**なのは Chrome 拡張（2021-02-01 に CWS 決済が完全廃止）/ VS Code（手数料 0%）/ Google Workspace / WordPress.org / Obsidian など。**プラットフォーム課金必須**なのは Shopify / Atlassian / Salesforce / monday.com
- Shopify は Billing API 必須だが手数料は **生涯累計 $100 万まで 0%**（超過 15%）。手数料では Stripe より有利だが、**入金スケジュールを握られる**ためオーナーの「貯めて後で現金化」とは合わない
- 取引意図のクエリ（"HSBC statement converter" 等）は、情報意図のクエリと違って AI Overviews に食われにくい。このリポジトリの既存結論（`english-saas-venture/research/acquisition-channels.md` の「SEO は期待値が下がった」）は**情報意図のクエリについての結論**であり、取引意図には当てはまらない
- 除外が確定した面: App Store の無料アプリ量産（4.3(b) が量産を名指しで禁止、繰り返すと Developer Program 除名）/ Raycast（課金機構が存在しない）/ Notion（発信主導 + Marketplace 外への誘導を規約で禁止）/ Canva（露出が手動キュレーション、かつ 1 位アプリが純正機能に食われて終了した実例）/ Obsidian（Templater は累計 390 万 DL に対しアクティブスポンサー 6 人）

## 作らない選択肢

**現時点ではこれを採っている。** 何を作るかは決めておらず、すぐに作る予定もない。
本調査の結論が「分野から選ぶのではなく、身近な反復作業から始める」である以上、
その反復作業が見つかるまでは作るものが決まらない。
