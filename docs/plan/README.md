# アイデア索引

ここで検討しているアイデアの一覧。セッションはまずこのファイルを読み、
続いて該当アイデアのディレクトリを読んでから始める。

## アイデアごとの構成

`docs/plan/<idea-slug>/` に以下を置く。書式は `docs/plan/_templates/` を参照。

- `overview.md` — 何を誰に。実在する痛み、既存プロダクトに足りないもの、作らない選択肢
- `experience.md` — 利用場面、中核の体験、便利さの定義、最初の版の体験範囲、実現性と技術スタック候補
- `decisions.md` — 決定の記録。追記のみ。決定 / 理由 / 却下した案とその理由
- `open-questions.md` — 未決の論点。何が決まれば決まるか / 材料 / 状態
- `research/` — 調査メモ。1 トピック 1 ファイル
  - `research/user-needs/` — ユーザーニーズの調査（公開の声の収集とオーナーの観察との突き合わせ）
  - `research/competitors/` — 既存・競合アプリの調査。1 製品 1 ファイル + `_comparison.md`
- `handoff.md` — 実装へ進むときに書く引き継ぎ（卒業時のみ）

グローバル skill が生成したファイルも、このアイデアのディレクトリ配下に置く。

## 状態

- `検討中` — 現在議論している
- `保留` — 止めている。再開の条件が open-questions.md にある
- `却下` — 作らないと決めた。理由は decisions.md にある
- `実装へ` — 実装に進むと決めた。handoff.md がある
