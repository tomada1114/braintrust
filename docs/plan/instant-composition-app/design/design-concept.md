# 瞬間英作文アプリ デザインコンセプト

作成: 2026-09-22。この文書は「何をどう決めたか、なぜか」を残す。そのまま使える値は `design-system.md`、
画面ごとのワイヤーとフローは `wireframes.md` にある。体験と流れの決定は `../decisions.md` と
`../experience.md` にあり、ここでは繰り返さない。

## 概要

| 項目 | 内容 |
|---|---|
| 一言でいうと | 日本語を見て英語を言い、自分で○×をつける表裏カードを、1 回 5 分・10 文前後で回す瞬間英作文アプリ |
| 主な利用状況 | 本来はスマホのスキマ時間（電車・待ち時間）。最初の版は PC のブラウザで試す |
| 利用文脈 | 1 枚ごとにカウントダウンがあり、目は表の日本語 → 残り秒 → 裏の英文の順に動く。操作は「めくる」と「○×」だけ |
| 画面の形 | PC でも縦長の 1 カラム（幅 420px 前後）。スマホにそのまま移せる形で作る |
| 言語 | 画面は日本語だけ。カードの裏は英語 |
| テーマ | ダークのみ |

## テーマ方針

- ダークのみ。ライトテーマも OS の外観への追従も作らない（`../decisions.md` 2026-09-22「見た目の方向は『夜のスコアボード』」）
- 理由: 暗い面では、小さな光と 1 色だけで手応えがはっきり出る。演出を盛らずに「視覚的に気持ちいい」を作れる
- 弱点: 明るい場所（昼の電車の窓際）で読めるかは実物で確かめる（`../open-questions.md`）
- 動きを減らす設定: OS の「動きを減らす」（macOS。iOS では「視差効果を減らす」。ブラウザでは prefers-reduced-motion）に従う。アプリの中にトグルは置かない
- ハイコントラストの設定: 本文は既に 15:1 以上なので値を変えない

## デザイン原則

4 つ。これ以上足さない。

### 1. 光るのは、この回に動いたものだけ

ネオングリーンは「○」「主な操作」「進行中の表示」「この回で増えた差分」にだけ使う。変わらなかった値は白か
グレーのまま静止させる。

- 効く判断: 終わりの画面で全部を光らせたくなったときに、この回で増えた値だけに絞る。追加の回でストリークが
  動かないなら、ストリークは静止させる
- 捨てるもの: 画面全体の華やかさ。祝う演出は小さく、成否と速さに連動させる

### 2. 数字が主役、文章は脇役

残り秒、コンボ、ストリーク、できた文の数を大きく、字間を詰めて出す。説明文は 1 行以内にする。

- 効く判断: 「今日の成長」を文章で説明したくなったら、数と差（「3 文が速くなった」「−1.2 秒」）に置き換える
- 捨てるもの: 丁寧な説明。気づきは数字の変化で伝える

### 3. ×は罰にしない

×と時間切れはグレーと「復習へ」の文字で示す。赤は使わない。×の数は数えない。

- 効く判断: エラーや警告の色が要る場面でも、×や復習に赤を流用しない。区別は位置・塗りと抜き・文字で行う
- 捨てるもの: 正誤が色で一目で分かる慣例

### 4. 子どもっぽくしない

マスコット、丸い太字の見出し、紙吹雪、感嘆符、褒め言葉の定型文を使わない。

- 効く判断: 「すごい！」を足したくなったら、秒数や差を出す（「前回より 1.2 秒速い」）
- 捨てるもの: 学習アプリの定番の親しみやすさ

## ブランド軸

| 軸 | 位置（1–5） | UI での現れ方 |
|---|---|---|
| 静か ⇔ にぎやか | 3 | 面は黒く静か。光るのは 1 色で、動いたものだけ |
| 硬質 ⇔ やわらかい | 3 | 大きな角丸と全丸のボタン（やわらかい）に、字間を詰めた数字と等幅の秒数（硬質） |
| 端正 ⇔ 手作り感 | 1 | イラストなし。図はリングと棒だけ |
| 情報密度 高 ⇔ 低 | 2 | 1 画面 1 つの問い。終わりの画面だけ縦に長い |
| 実直 ⇔ 遊び心 | 3 | 遊び心は言葉ではなく光と数字の動きに出す |

### 参照ロック

- 一次参照は Stryds ひとつ。方向で迷ったら Stryds 側に寄せる
- Stryds から保つもの: 黒い面 / ネオングリーン 1 色 / 大きな角丸と全丸 / 字間を詰めた大きな数字 / 影で飾らない
- 二次参照から借りるのは細部だけ: Uniswap Cup からは等幅の秒数、Steps / Queue からは暗いカードと棒、
  CapWords・Brilliant・Imprint からは締めの画面の順番
- 役割規則: ネオングリーンは design-system.md「色の役割」の 4 つにだけ使う。×・復習・見出し・装飾・背景には使わない
- 平均しない: 「暗い面 + 淡い複数色」に丸めない。リングも棒も、白・グレー・ネオングリーンだけで描く

## ボイス & トーン

- 画面は日本語。短く、事実を言う。感嘆符を使わない。褒め言葉の定型文（「すごい」「完璧」）を使わない
- 褒める代わりに数字を出す: 「前回より 1.2 秒速い」「3 文が速くなった」
- 操作の文言は動詞で終える: 「始める」「めくる」「次へ」「もう 10 文」「終わる」
- 設定と説明は敬体（「〜します」）、ボタンとラベルは体言か動詞の終止形
- この design/ 配下の文書は常体で書き、UI の文言は「」で引用する

### 用語

| 使う | 使わない | 対象 |
|---|---|---|
| 今日の分 | デイリー / 今日のレッスン | 1 日の最初の回 |
| 追加の回 / もう 10 文 | おかわり / ボーナス | 今日の分の後の回 |
| 表 / 裏 | 問題 / 答え | カードの面 |
| めくる | 答えを見る / チェック | 表から裏へ |
| 言えた（○）/ 言えなかった（×） | 正解 / 不正解 | 自己採点 |
| 復習へ | 不正解 / ミス | ×と時間切れの文 |
| 時間切れ | タイムオーバー | 残り秒が 0 |
| できた文 | 習得 / マスター | 別の日に 2 回、時間内に○の文 |
| 大トピック / 重点 | カテゴリ / お気に入り | 目的・場面の 2 段 |
| 難易度 | レベル | TOEIC 目安の 10 段階 |
| 連続 | コンボ（画面の文言では） | 連続○ |

確定した文言の一覧は `wireframes.md` の文言表にある。

## 非スコープ（デザインとして意図的に持たないもの）

| 持たないもの | 理由 | 代わりに満たす手段 |
|---|---|---|
| ライトテーマ / OS の外観への追従 | 1 色の光で手応えを出す方向が暗い面に依存する | ダークのみ。明るい場所での読みやすさは実物で確かめる |
| マスコット・イラスト | 子どもっぽさへの反発 | 数字、リング、棒 |
| 紙吹雪・大きな動き・画面全体の点滅 | 演出を大きくすると動機を下げうる（Kao ら CHI 2024）。テンポを壊す | カードの縁の光と数字の動きだけ |
| 赤（×・時間切れ・エラー） | ×を罰に見せない | グレーと「復習へ」。エラーは文言と記号 |
| ×の数・正答率 | 失点の積み上げは再開の心理的コストになる | 「復習に回った文」の数と一覧 |
| 大トピックごとの色分け | 1 色の決まり | リングの並び順とラベル |
| アプリ内の「動きを減らす」トグル | OS の設定に従うと決めた | prefers-reduced-motion |
| リーグ・ランキング | 反発が強い（知識ノート） | 自分の記録との比較だけ |

## 決定ログ

すべて 2026-09-22。原典と詳しい理由は `../decisions.md`。

| ラウンド | 決定したこと | 却下した選択肢 | 理由 |
|---|---|---|---|
| 1 | 調査は標準の範囲。画面は縦長の 1 カラムで、ワイヤーは 1 種類 | 軽め / 厚め、PC 向け、両方描く | 本来の場面はスマホで、今の画面をそのまま移せる |
| 2 | 方向は「夜のスコアボード」（Stryds が一次参照） | 白地の記録票（Strava）、明るい色面（Honk） | 小さな光と 1 色で手応えが出て、盛りすぎずに楽しい。子どもっぽくない |
| 2 | ×と時間切れは無彩色で「復習へ」 | 赤、復習用の副色 | ×を罰にしない決定とそろい、1 色の決まりを守る |
| 2 | 到達度は「できた文の数」と次の節目までのリング | 範囲の中の割合、両方 | 減らないので生成しても落ち込まない |
| 3 | 開始ボタンを 1 つ挟む | 即始まる、即始まるが計時を待つ | 開いただけで時間切れの×が付くのを防ぐ |
| 3 | キーは Space・矢印・F/J | 数字キー、マウスだけ | 左×・右○がスワイプに移る |
| 3 | 判定 10 文を初日の今日の分にする | 判定の後に続ける、別扱い | 初回も 5 分 |
| 4 | 難易度を出し、上がったら演出する | 出さない、静かに出す、上がったときだけ | オーナーの選択。○を甘くする動機は承知のうえ |
| 4 | 1 回の文の数は 10 / 15 / 20、既定 10（同日、別のセッションの「今日の分の枚数を自分で決められるようにする」で 5 / 10 / 15 / 20 / 30・すぐ反映に置き換わった） | 固定、1 日の目標文数 | オーナーの選択 |
| 4 | 時間切れの裏は自分で「次へ」 | 自動で次へ | 言えなかった文ほど読む |
| 4 | 追加の回も同じ終わりの画面 | 軽い締め | 画面が 1 つで済む |
| 4 | 効果音の既定はオン | オフ | PC で音の手応えも評価する |
| 5 | 1 日の区切りは午前 4 時 | 0 時、設定で変える | 夜更かしの日に今日の分が切れない |
| 5 | 終わりの画面の主な操作は「終わる」 | 「もう 10 文」を主に | 今日は完了で締める |
| 5 | 再開は中断した文から持ち時間を数え直す | 最後に回す、時間切れ扱い | 一番単純で、中断を罰にしない |
| 5 | ワイヤーの細部 7 つ（`wireframes.md` §5 の 4〜10） | 個別に見直す | 既存の決定から導いた細部 |
