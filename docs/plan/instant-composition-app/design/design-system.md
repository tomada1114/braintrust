## 2. 色

### 2.1 トークン

ライト / ダークの列は無い。ダークのみ（`design-concept.md`「テーマ方針」）。

| トークン | 値 | 用途 |
|---|---|---|

| `surface` | `#171717` | カード、シート、終わりの画面の各ブロック |
| `raised` | `#232323` | カードの中の一段上の面（別解のブロック、選択したカード、チップ） |
| `hairline` | `#333333` | 区切り線、リングと棒の溝、残り秒の棒の溝、まだの日の点。装飾扱い（コントラストの要件は無い） |
| `text/primary` | `#FDFDFD` | 本文、見出し、数字、リングと棒の塗り、済みの日の点 |
| `text/secondary` | `#9A9A9A` | 補足、ラベル、secondary ボタンの縁、累計の棒 |
| `text/review` | `#C8C8C8` | 「復習へ」チップの文字 |
| `text/disabled` | `#6F6F6F` | 無効の文字だけ。本文には使わない（Stryds の補足色だが黒の上で 4.18:1 しかない） |
| `accent` | `#A6FF00` | §2.2 の 4 つの役割だけ |
| `on-accent` | `#040126` | 強調色の面の上の文字 |
| `focus` | `#FDFDFD` | フォーカスの輪（2px、外側 2px 離す） |

### 2.2 強調色の役割

`accent` を使ってよいのは次の 4 つだけ。これ以外に使わない。

1. ○: ○のボタン、○を押した瞬間の縁の光、「速い n 秒」のチップ
2. 主な操作: 1 画面に 1 つだけの `button/primary`（「始める」「次へ」「もう 10 文」など）
3. 進行中の表示: 残り秒の棒、連続（コンボ）の数
4. この回で増えた差分: 「+3」「+10 pt」、今日のストリークの点、リングの今回分、上がった難易度の行、称号のカードの縁

使わない: ×、時間切れ、復習、見出し、装飾、背景、選択状態（選択は白で示す）、フォーカス（白の輪）、エラー。

### 2.3 状態を色だけで示さない

- ○と×: 位置（×は左、○は右）、塗りと縁取り、文字（「言えた」「言えなかった」）でも違う
- 時間切れ: 「時間切れ」の文字と「復習へ」チップ
- リングの今回分: 既存の白い塗りとの間に 2px の切れ目を入れ、「+n」の文字を添える（強調色と白のコントラストは 1.22:1 しかないため、境目は色ではなく切れ目で見せる）
- 週の点: 済み（塗り）/ 猶予（輪）/ 未（暗い点）の形の違いと、下の曜日ラベル

## 3. 文字

### 3.1 書体

| 役割 | 書体 | 太さ |

| 和文（表の日本語、UI の文言） | `"Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP", sans-serif` | 400 / 600 |

### 4.1 画面の縦の配分

- 主な操作（始める、めくる、○×、次へ）は画面の下 1/3 に置く（スマホで親指が届く位置。PC でも同じ位置）
- 中断・設定・閉じるは上端に置く
- カードの画面は上から「上端の帯（中断・進み・連続）→ カード → 残り秒の棒 → 操作」の順で固定し、1 画面に収める（スクロールさせない）

## 5. 部品の値

### 5.1 ボタン

| バリアント | 面 | 文字 | 縁 | 用途 |
|---|---|---|---|---|
| `primary` | `accent` | `on-accent`、和文 600 16 | なし | 1 画面に 1 つ。○もこれ |
| `secondary` | 透明 | `text/primary`、和文 600 16 | 1.5px `text/secondary` | ×、「終わる」、判定のやり直し |
| `text` | 透明 | `text/secondary`、和文 400 15 | なし | 「記録」「設定」「いまはやめる」 |

- 押下: 面を 8% 暗くする（`primary`）/ 面を `raised` にする（`secondary`）。拡大・縮小はしない
- 無効: `primary` は面を `raised`、文字を `text/disabled` にする
- キーの表示: PC ではボタンの右端に `chip/kbd` を出す（「Space」「→」）。タッチの端末では出さない

### 5.2 ○×の組（`grade-pair`）

```
┌───────────────────┐  ┌───────────────────┐
│ ←  言えなかった   │  │   言えた  →       │
└───────────────────┘  └───────────────────┘
  secondary（左）          primary（右）
```

- 左が×、右が○。幅は半分ずつ、間は 12
- 自分でめくった裏にだけ出す。時間切れの裏では `button/primary`「次へ」1 つに置き換える

### 5.3 カード（`flashcard`）

| 面 | 中身（上から） |
|---|---|
| `front` | 再出題なら `chip/again`「もう一度」→ 表の日本語（`front`、左寄せ）→ 余白 |
| `back-self` | 表の日本語（`body`、`text/secondary`、1 行に省略）→ 模範解答（`answer`）→ 別解のブロック（`raised`、`alt` を 2〜3 行）→ 要点（`point`、`text/secondary`、頭に「要点」ラベル）→ めくるまでの秒数（`mono-md`、「2.8 秒」） |
| `back-timeout` | `back-self` と同じ中身。秒数の代わりに「時間切れ」（`label`）と `chip/review`「復習へ」 |

- 面は `surface`、角丸 28、内側の余白 24、影なし
- 高さは 1 カラムの残りいっぱい（最小 280）。表と裏で高さを変えない

### 5.4 残り秒の棒（`timer-bar`）

| 項目 | 値 |
|---|---|
| 位置 | カードのすぐ下、左右はカードと同じ幅 |
| 高さ | 6、角丸 999 |
| 溝 | `hairline` |
| 塗り | `accent`。持ち時間から 0 へ直線的に縮む |
| 数字 | 棒の右に残り秒を `mono-md` で。整数の切り上げ（「5」「4」…）。単位は付けない |
| 0 になったとき | 塗りが消え、数字は「0」。色は変えない（赤にしない） |
| 持ち時間 | 英文の長さから出す。式は未決（`../open-questions.md`「カウントダウンの秒数の式」） |

### 5.5 チップ

| バリアント | 面 | 文字 | 縁 | 文言 |
|---|---|---|---|---|
| `review` | `raised` | `text/review`、`label` | なし | 「復習へ」 |
| `speed` | 透明 | `accent`、`label` + `mono-sm` | 1.5px `accent` | 「速い 2.1 秒」 |
| `again` | `raised` | `text/secondary`、`label` | なし | 「もう一度」 |

### 5.6 選択（`select-card` / `segmented` / `toggle`）

- `select-card`: 面 `surface`、未選択は縁なし。選択は面 `raised` + 1.5px `text/primary` の縁 + 右端に白いチェック。強調色を使わない
- 重点（サブトピック）の上限 2 に達したら、未選択のカードは `text/disabled` にして押せなくし、1 行で「重点は 2 つまで」と出す
- `segmented`: 溝 `raised`、選択中は面 `text/primary` に文字 `#000000`
- `toggle`: オンは溝 `text/primary` + 黒いつまみ、オフは溝 `raised` + 1.5px `text/secondary` の縁 + 灰色のつまみ。右に「オン」「オフ」を文字で出す

### 5.8 ストリーク（`week-row` + `stat/lg`）

- 数字: 「12」（`number-lg`）+「日連続」（`label`）。今日の分でこの回に増えたなら数字を `accent`、それ以外は `text/primary`
- 週の並び: 月〜日の 7 つの点（直径 12、間 16）と曜日ラベル（`caption`）

| 状態 | 見た目 |
|---|---|
| 済み | `text/primary` の塗り |
| 今日済み（この回で付いた） | `accent` の塗り |
| 猶予を使った日 | `text/primary` の 1.5px の輪（中は空） + ラベルの下に「休」 |
| 未（休んで猶予も無かった日） | `hairline` の塗り |
| これから | `hairline` の 1px の輪 |

- 並びの下に 1 行: 「今週の休み あと 1 回」（`caption`、`text/secondary`）。数えるルールは設定画面ではなく記録画面の下に 1 行で書く（Steps の注記の置き方）

## 6. 動きと音

### 6.1 動き

1 枚ごとの手応えは最大 320ms で終え、そのあと次の表を出して計時を始める。回転（カードの 3D の裏返し）、紙吹雪、
画面全体の点滅、揺れは使わない。

| 出来事 | 通常 | 動きを減らす設定のとき | 音 |
|---|---|---|---|
| めくる（自分で / 時間切れ） | 表の中身が 8px 上へずれて消え、裏の中身が下から 8px で出る。180ms、ease-out | 即時に切り替える | なし |
| ○（ふつう） | カードの縁に 2px の `accent` の輪 + 外側に 24px のぼかしの光（`accent` 35%）が出て消える。240ms | 縁の輪だけを 400ms 出して消す（ぼかしなし） | ○の音 |
| ○（速い） | ふつうの光 + `chip/speed` が 8px 上がりながら出る。320ms | 光なしの縁の輪 + チップを即時に出す | ○の音（1 段高い） |
| 連続 +1 | 数字が 1.15 倍になって 120ms で戻る | 数字だけ変わる | 連続の音（連続数に応じて音程を上げ、5 で頭打ち） |
| 連続が切れる | 連続の表示が 120ms で消える | 即時に消える | なし |
| ×を押したとき | カードの `answer` の文字を 160ms で `text/secondary` に落としてから次の表へ（何も跳ねない） | 即時 | なし |
| 時間切れ | 自動でめくる（上の「めくる」と同じ）。模範解答は読むための面なので、文字は落とさない | 即時 | なし |
| 次のカード | 120ms で出る（フェード） | 即時 | なし |
| 終わりの画面 | 今回動いた値だけ、上から 150ms ずつずらして数え上げる（1 つ最大 600ms）。リングの今回分は 600ms で伸びる。変わらない値は最初から最終値 | すべて最終値で即時に出す | 締めの音 1 回 |
| 難易度が上がった | `difficulty-line` の文字が 400ms 光る（`accent` の文字の周りに 12px のぼかし） | 光なし | 締めの音に含める |
| 称号 | `milestone-card` が 200ms で出る | 即時 | 締めの音に含める |

- 「速い」の判定: 持ち時間の半分以内にめくった○。閾値は試しながら決める（`../open-questions.md`「○の手応えの段階」）
- 残り秒の棒は情報なので、動きを減らす設定でも縮ませる（毎秒 1 段ずつの段階で縮めてよい）

### 6.2 音

| 音 | 鳴る時 | 長さの目安 |
|---|---|---|
| ○の音 | ○を押した瞬間（速いときは 1 段高い） | 80ms 前後 |
| 連続の音 | 連続が 2 以上になった瞬間（○の音に重ねず、置き換える） | 100ms 前後 |
| 締めの音 | 終わりの画面が出た瞬間 | 600ms 前後 |

- 3 種類だけ。×・時間切れ・エラーには鳴らさない
- 既定はオン（`../decisions.md` 2026-09-22「効果音の既定はオン」）。設定と開始画面のスピーカーで切る
- 音源の選定は実装側。電子音の短い単音で、声や拍手は使わない

| ← / F | — | 言えなかった（×） | — | — |
| Esc | 中断のシートを開く | 同じ | 同じ | シートを閉じる |
| Tab | フォーカスを順に移す（どの画面でも） | | | |

- めくるまでの秒数は、表を出した瞬間からめくるキー（またはクリック）までを測る
- 裏で Space を押しても何も起きない（○×を飛ばさせない）
- キーの取りこぼしを防ぐため、裏を出してから 150ms は○×のキーを受け付けない（めくる勢いで○を押す誤操作を防ぐ）

## 8. アクセシビリティ

| 項目 | 基準 | このアプリでの扱い |
|---|---|---|
| 文字のコントラスト | 4.5:1 | すべての本文・ラベル・数字。実測は §9 |
| 文字以外のコントラスト | 3:1 | ボタンの縁、リングと棒の塗り、週の点、フォーカスの輪。実測は §9 |
| フォーカス | 見える | 白の 2px の輪を外側 2px に。強調色を使わない |
| キーボード | 全操作 | §7。マウスなしで初回から設定まで完結する |
| 動きを減らす | OS の設定に従う | §6.1 の右の列 |
| 色だけに頼らない | — | §2.3 |
| 読み上げ | 状態を伝える | 表を出したら「表。〈日本語〉。持ち時間 8 秒」、時間切れで「時間切れ。復習へ」、○で「言えた」、×で「復習へ」を `aria-live="polite"` で。残り秒は毎秒読み上げない |
| タップの的 | 44 × 44 以上 | ボタンは高さ 56 |

### 制限: 残り秒は目で見る前提

時間制限は体験の中核なので、読み上げの利用者に向けて持ち時間を延ばす設定は持たない。これは割り切った制限として記録する。

## 10. 実装セッションへの指示

- 値はこの文書から作る。`tokens.css` などは実装側のリポジトリに置く
- `accent` の使い道は §2.2 の 4 つだけ。コードレビューで `accent` の参照箇所を数え、役割外の使用を止める
- 影（`box-shadow` の立体の影）を使わない。○の光だけは例外で、§6.1 の値で一瞬だけ出す
- `prefers-reduced-motion: reduce` のときは §6.1 の右の列に切り替える。動きのライブラリを使う場合も、この分岐を必ず通す
- 効果音は既定オン。ブラウザの自動再生の制限があるので、最初の「始める」の操作で音声を有効にする
- 残り秒の計測は表の表示から。描画の遅れを秒数に入れないよう、表が描画された時刻を起点にする
- 持ち時間の式、「速い」の閾値、到達度の節目の刻みは未決。いずれも設定ファイルなどで変えられる形にしておく（`../open-questions.md`）
