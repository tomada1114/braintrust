## 0. 凡例

| 記法 | 意味 |
|---|---|
| 外側の `┌─┐` | 1 カラム（幅 420px 前後）。PC では画面の中央に置き、外側は黒 |
| 内側の `┌─┐` | カード（`surface`）、または選択のカード |
| `╔═╗` | ○を押した瞬間の光った縁（`accent`） |
| `[ 始める ]` | `button/primary`（強調色の塗り）。1 画面に 1 つ |
| `( もう 10 文 )` | `button/secondary`（縁取り） |
| `〔復習へ〕` `〔もう一度〕` `〔速い 2.1 秒〕` | チップ |
| `━━━━──  5` | 残り秒の棒と残り秒 |
| `● ◎ ○ ─ ·` | 週の点: 済み / 今日済み（強調色） / 猶予を使った日 / 未 / これから |
| 入れ子の `╭─╮` | 到達度のリング（外から大トピックの順） |
| `♪` | 効果音のオン・オフ |
| `✕` | 閉じる・中断 |

- 文言は例示を含む。確定した文言は §4.5 の文言表にある
- 例文は例示。実際の例文は `../card-skills-design.md` の生成スキルが作る
- 全角文字と罫線の幅は表示環境でずれることがある。配置の関係を読む図として扱う

## 2. 画面

### W1 初回: 使う場面を選ぶ

登場フロー: F1 の 1 手目。記録が何もないときだけ出る。
この画面の役割: 使う大トピックを 1 つ以上選ばせる。

```
┌──────────────────────────────────────────────┐
│                                              │
│ ようこそ                                     │
│ 使う場面を選んでください                     │
│ いくつでも選べます。あとで設定で変えられます │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │ 日常                          ✓          │ │
│ └──────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────┐ │
│ │ 仕事                          ✓          │ │
│ └──────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────┐ │
│ │ 旅行                                     │ │
│ └──────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────┐ │
│ │ IT・技術                                 │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│                                              │
│ [               次へ   Enter               ] │
└──────────────────────────────────────────────┘
```

注記

- 大トピックは一覧ファイルの順に並べる（`../decisions.md` 2026-09-22「トピックは固定の一覧」）
- 1 つも選んでいないあいだ「次へ」は無効。押せない理由は 1 行で出す（§4.9）
- 重点（サブトピック）はここでは聞かない。初回の手間を増やさないため。重点は設定（W11）で選ぶ
- 選択は白いチェックと明るい面で示す。強調色は使わない（`design-system.md`「強調色の役割」）

### W2 初回: 判定の前の説明

登場フロー: F1 の 2 手目、F8 の 3 手目（測り直しのときは 1 行目だけ「10 文で難易度を測り直します」に変わる）。
この画面の役割: 判定のしくみと操作を 1 画面で伝え、始めさせる。

```
┌──────────────────────────────────────────────┐
│                                              │
│ 最初の 10 文で難易度を測ります               │
│ 易しい文から順に出ます。                     │
│ この 10 文が今日の分になります               │
│                                              │
│ 1. 日本語を見て、英語を言う                  │
│    （声に出すか、頭の中で）                  │
│ 2. 言えたらめくる。時間が切れると            │
│    自動でめくれます                          │
│ 3. 裏を見て、自分で ○ か × をつける          │
│                                              │
│ Space めくる   → J 言えた   ← F 言えなかった │
│                                              │
│ [              始める   Space              ] │
└──────────────────────────────────────────────┘
```

注記

- 説明はこの 1 画面だけ。チュートリアルの重ね表示（オーバーレイ）は作らない
- キーの行は PC だけに出す。タッチの端末では出さない
- 判定の 10 文は易しい順に出し、×の再出題はしない（`../decisions.md` 2026-09-22「初回の判定 10 文を初日の今日の分にする」）

### W3a 開始画面: 今日の分・未開始

登場フロー: F2 の 1 手目。2 日目以降にアプリを開くとここに来る。
この画面の役割: 今日やることを見せ、1 回押すだけで始めさせる。

```
┌──────────────────────────────────────────────┐
│ ♪                              記録   設定   │
│                                              │
│ 12                                           │
│ 日連続                                       │
│ 月  火  水  木  金  土  日                   │
│ ●   ●   ○   ●   ●   ·   ·                    │
│         休                                   │
│ 今週の休み あと 0 回                         │
│                                              │
│ 今日の分                                     │
│ 10 文 ・ 約 5 分                             │
│ 復習 4 ・ 新しい文 6 ・ 重点 会議            │
│                                              │
│                                              │
│ [              始める   Space              ] │
└──────────────────────────────────────────────┘
```

注記

- 選ぶものは置かない。「始める」か Space / Enter で始まる（`../decisions.md` 2026-09-22「今日の分は開始ボタンを 1 つ挟んで始める」）
- 「復習 4 ・ 新しい文 6 ・ 重点 会議」は配合の結果を見せるだけで、変えられない。重点が無いときは「重点」を出さない
- 週の並びはこの時点では今日の点が「これから」。今日の分を終えると `◎` になる（W3c）
- 左上の `♪` で効果音を切り替える（既定はオン）。右上の「記録」「設定」は `button/text`

### W3b 開始画面: 今日の分・途中

登場フロー: F5 の再開。同じ日に、今日の分を途中で閉じた後に開くとここに来る。

```
┌──────────────────────────────────────────────┐
│ ♪                              記録   設定   │
│                                              │
│ 12                                           │
│ 日連続                                       │
│ 月  火  水  木  金  土  日                   │
│ ●   ●   ○   ●   ●   ·   ·                    │
│         休                                   │
│                                              │
│ 今日の分  途中                               │
│ 4 / 10 まで進んでいます                      │
│                                              │
│                                              │
│ [             続きから   Space             ] │
└──────────────────────────────────────────────┘
```

注記

- 「続きから」で、中断した文の表から再開する。その文の持ち時間は最初から数え直す（§5 の 3）
- 連続（コンボ）は 0 に戻る
- 日をまたいだら、この画面ではなく W3a（新しい今日の分）になる。前日の残りは捨てる

### W3c 開始画面: 今日は完了

登場フロー: F2 の後、F6 の入口。今日の分を終えた日に開くとここに来る。

```
┌──────────────────────────────────────────────┐
│ ♪                              記録   設定   │
│                                              │
│ 13                                           │
│ 日連続                                       │
│ 月  火  水  木  金  土  日                   │

│         休                                   │
│                                              │
│ 今日は完了                                   │
│ 今日 2 回 ・ 20 文                           │
│                                              │

│ [            もう 10 文   Space            ] │

注記

- 主な操作は「もう 10 文」（文の数は設定の値）。今日の分は終わっているので、ここでは続けることを主にする

- 「今日 2 回 ・ 20 文」は今日の分と追加の回の合計

### W3d 開始画面: 出せる文が足りない

登場フロー: F2 の端の状態。
この画面の役割: 点検済みの文が足りず今日の分を組めないことを伝える。

```
┌──────────────────────────────────────────────┐
│ ♪                              記録   設定   │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │ 出せる文が足りません                     │ │
│ │ 点検済みの文が 3 文しかありません。      │ │
│ │ カードの生成と点検を実行してください     │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│ (            設定で範囲を広げる            ) │
└──────────────────────────────────────────────┘
```

注記

- 出せる文が 5 文以上あれば、ある分だけで今日の分を組み、「今日の分 7 文」と出して通常どおり進める。5 文未満のときだけこの画面になる（§5 の 7）
- 「出せる文」は、選んだ大トピックの中で、点検済み（ハッシュが一致）で、今の難易度の範囲にある文
- 自分用の段階なので、生成と点検のスキルを実行するよう直接書く

### W4 カードの表

登場フロー: F3 の 1 手目。
この画面の役割: 日本語を見せ、残り秒を減らしていく。

```
┌──────────────────────────────────────────────┐
│ ✕ 中断 Esc          7 / 10      3 連続       │
│ ┌──────────────────────────────────────────┐ │
│ │                                          │ │
│ │                                          │ │
│ │ 会議を来週に延ばせますか？               │ │
│ │                                          │ │
│ │                                          │ │
│ │                                          │ │
│ └──────────────────────────────────────────┘ │
│ ━━━━━━━━━━━━━━━━━━━━━━━━──────────  5        │
│                                              │
│                                              │
│ [              めくる   Space              ] │
└──────────────────────────────────────────────┘
```

注記

- 表を描画した瞬間から計時する。棒は持ち時間から 0 へ縮み、右の数字は残り秒（整数）
- 上端の帯: 左に中断、中央に進み（等幅）、右に連続（2 以上のときだけ、強調色）
- 「めくる」かカードそのものを押すとめくれる。Space / Enter でもめくれる
- 0 になると自動でめくれて W6 になる

### W5 カードの裏: 自分でめくった

登場フロー: F3 の 2 手目。
この画面の役割: 模範解答・別解・要点を見せ、自分で○×をつけさせる。

```
┌──────────────────────────────────────────────┐
│ ✕ 中断 Esc          7 / 10      3 連続       │
│ ┌──────────────────────────────────────────┐ │
│ │ 会議を来週に延ばせますか？               │ │
│ │                                          │ │
│ │ Can we push the meeting                  │ │
│ │ to next week?                            │ │
│ │ ┌──────────────────────────────────────┐ │ │
│ │ │ Could we move the meeting            │ │ │
│ │ │ to next week?                        │ │ │
│ │ │ Can we postpone the meeting          │ │ │
│ │ │ until next week?                     │ │ │
│ │ └──────────────────────────────────────┘ │ │
│ │ 要点  push A to B で予定を後ろへ         │ │
│ │                                          │ │
│ │                           2.8 秒         │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│ (  ← 言えなかった   )  [     言えた →      ] │
└──────────────────────────────────────────────┘
```

注記

- 上から: 表の日本語（1 行に省略、補足の色）→ 模範解答 → 別解（一段明るい面に 2〜3 個）→ 要点 → めくるまでの秒数
- ○×は画面の下に左右で並べる。左が×（縁取り）、右が○（強調色の塗り）
- ← / F で×、→ / J で○。裏を出してから 150ms はキーを受け付けない（`design-system.md`「キー操作」）
- 秒数は「2.8 秒」の形で、比較（前回との差）はここでは出さない。比較は終わりの画面でまとめて見せる

### W7 ○を押した瞬間

登場フロー: F3 の○の枝。W5 の上で起きる一瞬の状態で、独立した画面ではない。

```
┌──────────────────────────────────────────────┐
│ ✕ 中断 Esc          7 / 10      4 連続       │
│ ╔══════════════════════════════════════════╗ │
│ ║ 会議を来週に延ばせますか？               ║ │
│ ║                                          ║ │
│ ║ Can we push the meeting                  ║ │
│ ║ to next week?                            ║ │
│ ║                                          ║ │
│ ║                〔速い 2.1 秒〕           ║ │
│ ╚══════════════════════════════════════════╝ │
│ ↑ 縁が 1 回光る（240〜320ms）                │
│                                              │
│ (  ← 言えなかった   )  [     言えた →      ] │
└──────────────────────────────────────────────┘
```

注記

- ふつう: 縁が 1 回光る。速い（持ち時間の半分以内にめくった）: 縁の光 + `〔速い 2.1 秒〕`
- 連続が 1 増える（右上）。音は○の音、連続が 2 以上なら連続の音
- 手応えは最大 320ms。そのあと次の表（W4）が出て、計時が始まる
- ×を押したときは光らない。模範解答の文字が補足の色に落ちて、次の表へ進む
- 動きの値と、動きを減らす設定のときの置き換えは `design-system.md`「動き」

### W8 中断のシート

登場フロー: F5。カードの画面で Esc か「✕ 中断」を押したとき。

```
┌──────────────────────────────────────────────┐
│ ✕ 中断 Esc          7 / 10                   │
│ ┌──────────────────────────────────────────┐ │
│ │                                          │ │
│ │                                          │ │
│ │ （表は隠す。残り秒は止まる）             │ │
│ │                                          │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │ ここで中断しますか                       │ │
│ │ 今日のうちなら 7 枚目から                │ │
│ │ 続けられます                             │ │
│ │                                          │ │
│ │ (             いまはやめる             ) │ │
│ │ [             続ける   Esc             ] │ │
│ └──────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

注記

- シートが出ているあいだは表を隠し、残り秒を止める（止めている間に考えられないようにする）
- 「続ける」（Esc でも）で、止めた残り秒から再開する。連続は保つ
- 「いまはやめる」で開始画面（W3b）へ。タブを閉じた場合も同じ扱い
- 中断はストリークにもポイントにも数えない。今日の分を最後まで終えた日だけがストリークになる

│ ▁▂▁▃▂▄▃▂▅▃▄▂▃▆  （直近 14 日）               │
│                                              │
│ (                もう 10 文                ) │
│ [              終わる   Space              ] │
└──────────────────────────────────────────────┘
```

注記

- 並び順は伝えたい順: 今日の成長 → 復習に回った文 → ストリーク → 難易度 → 到達度 → 称号 → ポイントと累計。
  最初の画面の高さに「今日の成長」と「復習に回った文」が入るようにする
- 今日の成長: 復習で出た文を前回と比べる。「速くなった文」（めくるまでの秒数が前回より短い○）と「×→○」の数を大きく出し、
  下に 3 行だけ差を並べる。比べる相手がいない（新しい文だけの）回は「初めての n 文」とだけ出す
- 復習に回った文: ×と時間切れの文の数と一覧。×の数・正答率は出さない。再出題で言えた文も、後日の復習には回るのでここに並ぶ
- ストリーク: 今日の分の回だけ数字が増え、今日の点が `◎` になる。追加の回では静止
- 難易度: 上がった回だけ行が光る（`↑`）。下がった回は同じ文言に `↓`、光らない。変わらない回は行ごと出さない
- 到達度: 大トピックごとのリング。この回で増えた分だけ強調色で伸び、「+3」が付く。「次の節目まで」は一番近いものを 1 つだけ
- 称号: 節目に達した回だけカードが出る。称号の名前と節目の刻みは未決（`../open-questions.md`）
- ポイント: この回の分（やり切りで付く）と合計。累計は言った文と練習した日、直近 14 日の棒
- 動くのはこの回に変わった値だけ。変わらない値は最初から最終値で出す（`design-concept.md` 原則 1）
- 主な操作は「終わる」（Space）。「もう 10 文」は縁取り（§5 の 2）。右上の ✕ も「終わる」と同じ
- 途中で「すべて見る」を開いても、ボタンの位置は画面の下に固定する

## 3. フロー

### F1 初回

```
[起動・記録なし] -> [W1 場面を選ぶ] -> [W2 説明] -> [W4 -> W5/W6] x 10（易しい順・再出題なし）
                                                          |
                                                          v
                                  [W9f 終わりの画面（判定の結果）] -> 終わる -> [W3c 今日は完了]
```

1. 初めて開くと W1。大トピックを 1 つ以上選び「次へ」
2. W2 で判定のしくみとキーを読み、「始める」
3. 易しい順に 10 文。1 枚ごとの流れは F3。×と時間切れの文は再出題せず、後日の復習に回る
4. W9f で判定の結果（難易度）と、通常の終わりの画面を見る。ストリーク 1 日目
5. 「終わる」で W3c。「もう 10 文」なら F6

### F2 今日の分

```
[W3a 開始画面] -> 始める -> [F3] x N -> ×か時間切れがあった? --いいえ--> [W9]
                                               | はい
                                               v
                                   [W4r もう一度] x その数（F3 と同じ）-> [W9] -> 終わる -> [W3c]
```

1. 開くと W3a。「始める」か Space
2. N 文（設定の枚数。既定 10）を F3 で進める
3. ×と時間切れの文があれば、出た順にもう一度出す（F4）
4. W9 で締める。ストリークが 1 増える
5. 「終わる」で W3c。「もう 10 文」なら F6

### F3 1 枚の中

```
[W4 表・計時開始] --めくる(Space/Enter/クリック)--> [W5 裏] --○(→/J)--> [W7 手応え] -> 次の W4
       |                                               \
       | 残り 0                                         --×(←/F)--> 次の W4
       v
[W6 裏・時間切れ・×を自動で記録] --次へ(Space)--> 次の W4
```

1. 表を描画した瞬間から計時する
2. 自分でめくると W5。めくるまでの秒数を記録する
3. ○を押すと W7 の手応え（最大 320ms）のあと、次の表へ。×を押すと手応えなしで次の表へ
4. 時間切れなら自動でめくれて W6。×は自動で記録。「次へ」で次の表へ
5. 最後の 1 枚の後は、F4（もう一度）か終わりの画面へ

### F4 ×の再出題

1. 通常の N 文を終えた時点で、×と時間切れの文を出た順に並べる
2. 1 枚ずつ W4r（`〔もう一度〕`）で出す。流れは F3 と同じで、時間切れもある
3. もう一度の結果も記録する。ただし同じ日の 2 回目の○なので、到達度（別の日に 2 回）には数えない
4. もう一度でも×か時間切れなら、後日の復習に回るだけで、それ以上は出さない
5. もう一度の文の○×は、終わりの画面の「今日の成長」の比較には使わない（その回の 1 回目の結果で比べる）

### F5 中断と再開

```
[W4/W5/W6] --Esc / ✕ 中断--> [W8 シート（表を隠す・残り秒を止める）]
                                  |                     |
                            続ける(Esc)              いまはやめる / タブを閉じる
                                  |                     |
                     止めた残り秒から再開          [W3b 途中]（同じ日）
                                                        |
                                            続きから -> 中断した文の表（持ち時間は数え直す・連続は 0）

[翌日以降に開く] -> [W3a 新しい今日の分]（前日の残りは捨てる）
```

1. カードの画面で Esc か「✕ 中断」を押すと W8。表を隠し、残り秒を止める
2. 「続ける」で、止めた残り秒から再開する。連続は保つ
3. 「いまはやめる」かタブを閉じると、そこまでの記録を保存して W3b へ
4. 同じ日に開くと W3b。「続きから」で、中断した文から。持ち時間は最初から数え直し、連続は 0
5. 日の区切りを越えて開くと W3a の新しい今日の分。前日は今日の分を終えていないので、前日の点は「未」か、猶予が残っていれば「休」になる。前日の未回答の文は、次の配合の候補に戻る
6. 日の区切りは午前 4 時（`../decisions.md` 2026-09-22「1 日の区切りは午前 4 時」）

### F6 追加の回

1. W9 か W3c で「もう 10 文」（文の数は設定の値）
2. 通常と同じ配合で次の N 文。流れは F2 の 2〜3 と同じ
3. W9 で締める。ストリークは動かず静止。この回で変わった値（成長、ポイント、累計、到達度、難易度）だけが動く
4. 「終わる」で W3c

### F7 設定を変える

1. W3 の「設定」から W11
2. 大トピック・重点・枚数・効果音を変える。その場で保存する
3. 枚数はその日の分にもすぐ反映する。途中の今日の分なら残りの枚数が変わり、すでに終えた枚数が新しい枚数以上なら「今日は完了」になる
4. 大トピックと重点は、今日の分をまだ始めていなければ今日の分から、途中なら次の回から効く
5. 「← 戻る」で W3

### F8 難易度を測り直す

1. W11 の「難易度を測り直す」
2. W12 で「測り直す」
3. W2（1 行目が「10 文で難易度を測り直します」）→ 易しい順に 10 文（F1 の 3 と同じ）
4. W9f。「次から TOEIC 730 前後の文」
5. 今日の分がまだだった日はこれが今日の分になり、ストリークが増える。終えていた日は追加の回と同じ扱い

### F9 記録を見る

1. W3 の「記録」から W10
2. 大トピックの行を開くと、サブトピックごとの横棒が出る
3. 「← 戻る」で W3

| トースト | 「記録を保存できませんでした。サーバーが動いているか確かめてください」 |

### 4.6 エラーの扱い

最初の版は PC のローカルサーバー + SQLite（`../experience.md`）。エラーは自分で直せる形で伝える。赤は使わない。

| エラー | 形式 | 文言 | その後 |
|---|---|---|---|
| 記録の保存に失敗 | トースト（4 秒） | 「記録を保存できませんでした。サーバーが動いているか確かめてください」 | 回答はブラウザの中に持っておき、次の回答のときに送り直す。練習は止めない |
| 終わりの画面の時点で未保存がある | 終わりの画面の先頭に 1 行 | 「保存できていない記録が 2 件あります」+「送り直す」 | 送れたら行を消す |
| 例文の読み込みに失敗 | W3d と同じ形 | 「例文を読み込めませんでした」+「読み込み直す」 | — |
| 出せる文が足りない | W3d | §4.5 | — |

### 4.7 読み込みと手応え

- 今日の分の N 文と、もう一度に使う裏の中身は「始める」の時点でまとめて読み込む。カードの間で読み込み待ちを出さない（計時が歪むため）
- 開始画面の読み込みが 300ms を超えたら、ボタンと数字の位置だけの骨組みを出す。回る印（スピナー）は使わない
- 成功のトーストは出さない。記録の保存が成功したことは知らせない（手応えは○の光と終わりの画面で足りている）

### 4.8 アクセシビリティ

`design-system.md`「アクセシビリティ」のとおり。画面ごとの補足だけをここに書く。

- W4〜W6: 表を出したら「表。〈日本語〉。持ち時間 8 秒」、時間切れで「時間切れ。復習へ」を読み上げる
- W8: シートが出たらフォーカスをシートの中に閉じ込め、「続ける」に置く
- W9: 見出し「今日は完了」にフォーカスを置く。数え上げの途中の値は読み上げず、最終値だけを読む
- W11: 重点の上限で押せなくなったチップは、押せない理由（「重点は 2 つまで」）を読み上げる

### 4.9 入力の検証（設定と初回）

| 項目 | 規則 | 伝え方 |
|---|---|---|
| 大トピック（W1） | 1 つ以上 | 「次へ」を無効にし、下に「1 つ選ぶと次へ進めます」 |
| 大トピック（W11） | 1 つ以上。最後の 1 つは外せない | 外そうとしたら、その行の下に「1 つは選んでください」。選択は外れない |
| 重点（W11） | 0〜2 個。選んだ大トピックのサブトピックだけ | 2 つ選ぶと他は押せなくなり、「重点は 2 つまで」 |
| 重点の大トピックを外したとき | その大トピックの重点も外れる | 重点の行に 1 行「〈会議〉の重点を外しました」 |
| 今日の分の枚数（W11） | 5 / 10 / 15 / 20 / 30 のどれか | 選択式なので誤りは起きない |

検証はその場で行う（押した瞬間）。フォームの送信は無い。

## 5. このワイヤーで決めた細部

当方が案として置き、2026-09-22 にオーナーが了承したもの。原典は `../decisions.md`。

1. 1 日の区切りは午前 4 時（「1 日の区切りは午前 4 時」）
2. 終わりの画面の主な操作は「終わる」、「もう 10 文」は縁取り。完了後の開始画面（W3c）では「もう 10 文」を主にする（「終わりの画面の主な操作は『終わる』」）
3. 途中で閉じて同じ日に再開したら、中断した文から。持ち時間は最初から数え直し、連続は 0（「途中で閉じた今日の分は、中断した文から持ち時間を数え直して再開する」）
4. 中断のシートの間は表を隠し、残り秒を止める。「続ける」で止めた残り秒から再開し、連続は保つ（以下 4〜10 は「ワイヤーの細部」）
5. 判定の測り直しは、今日の分がまだならそれを今日の分とし、終えていれば追加の回と同じ扱い
6. 開始画面に配合の内訳（「復習 4 ・ 新しい文 6 ・ 重点 会議」）を出す
7. 出せる文が 5 文以上なら、ある分だけで今日の分を組む。5 文未満のときだけ W3d
8. もう一度の文の結果は、今日の成長の比較にも到達度にも使わない
9. 裏を出してから 150ms は○×のキーを受け付けない
10. 記録の保存に失敗しても練習は止めず、次の回答のときに送り直す

枚数（5 / 10 / 15 / 20 / 30、既定 10、すぐ反映）は別のセッションで決まった（「今日の分の枚数を自分で決められるようにする」）。
このワイヤーの「10 文」「もう 10 文」は既定の枚数での例示で、実際には設定の枚数が入る。

未決のまま残っている画面の論点は `../open-questions.md`（○の手応えの段階、到達度の節目の刻みと称号、明るい場所での読みやすさ、持ち時間の式）。
