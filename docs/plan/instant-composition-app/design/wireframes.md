# 瞬間英作文アプリ ワイヤーとフロー

作成: 2026-09-22。体験の決定は `../decisions.md` と `../experience.md` にあり、ここでは繰り返さない。
ここには画面とフローだけを描く。色・大きさ・動き・キーの値は `design-system.md` にあり、この文書では繰り返さない。

## 0. 凡例

| 記法 | 意味 |
|---|---|
| 外側の `┌─┐` | 1 カラム（幅 420px 前後）。PC では画面の中央に置き、外側は黒 |
| 内側の `┌─┐` | カード（`surface`）、または選択のカード |
| `╔═╗` | ○を押した瞬間の光った縁（`accent`） |
| `[ 始める ]` | `button/primary`（強調色の塗り）。1 画面に 1 つ |
| `( もう 10 文 )` | `button/secondary`（縁取り） |
| `〔復習へ〕` `〔もう一度〕` `〔速い 2.1 秒〕` | チップ |
| `━━━━──  5` | 残り秒の棒と残り秒 |
| `● ◎ ○ ─ ·` | 週の点: 済み / 今日済み・この回で埋まった日（強調色） / 取り返せる空き（下に「空」） / 未 / これから |
| 入れ子の `╭─╮` | 到達度のリング（外から大トピックの順） |
| `♪` | 効果音のオン・オフ（`icon-button`。オフのときは斜線） |
| `✕` | 閉じる・中断（`icon-button`） |

- 文言は例示を含む。確定した文言は §4.5 の文言表にある
- 例文は例示。実際の例文は `../card-skills-design.md` の生成スキルが作る
- 全角文字と罫線の幅は表示環境でずれることがある。配置の関係を読む図として扱う

## 2. 画面

### W1 初回: 使う場面を選ぶ

登場フロー: F1 の 1 手目。記録が何もないときだけ出る。
この画面の役割: 使う大トピックを 1 つ以上選ばせる。

```
┌──────────────────────────────────────────────┐
│                                              │
│ ようこそ                                     │
│ 使う場面を選んでください                     │
│ いくつでも選べます。あとで設定で変えられます │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │ 日常                          ✓          │ │
│ └──────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────┐ │
│ │ 雑談・人付き合い                         │ │
│ └──────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────┐ │
│ │ 仕事                          ✓          │ │
│ └──────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────┐ │
│ │ 旅行                                     │ │
│ └──────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────┐ │
│ │ IT・技術                                 │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│ [               次へ   Enter               ] │
└──────────────────────────────────────────────┘
```

注記

- 大トピックは一覧ファイルの順に並べる（`../decisions.md` 2026-09-22「トピックは固定の一覧」）。プロダクト側の `content/taxonomy.json` では 5 つ（日常 / 雑談・人付き合い / 仕事 / 旅行 / IT・技術）で、この画面に全部が並ぶ
- 1 つも選んでいないあいだ「次へ」は無効。押せない理由は 1 行で出す（§4.9）
- 重点（サブトピック）はここでは聞かない。初回の手間を増やさないため。重点は設定（W11）で選ぶ
- 選択は白いチェックと明るい面で示す。強調色は使わない（`design-system.md`「強調色の役割」）

### W2 初回: 判定の前の説明

登場フロー: F1 の 2 手目、F8 の 3 手目（測り直しのときは 1 行目だけ「10 文で難易度を測り直します」に変わる）。
この画面の役割: 判定のしくみと操作を 1 画面で伝え、始めさせる。

```
┌──────────────────────────────────────────────┐
│                                              │
│ 最初の 10 文で難易度を測ります               │
│ 易しい文から順に出ます。                     │
│ この 10 文が今日の分になります               │
│                                              │
│ 1. 日本語を見て、英語を言う                  │
│    （声に出すか、頭の中で）                  │
│ 2. 言えたらめくる。時間が切れると            │
│    自動でめくれます                          │
│ 3. 裏を見て、自分で ○ か × をつける          │
│                                              │
│ Space めくる   → J 言えた   ← F 言えなかった │
│                                              │
│ [              始める   Space              ] │
└──────────────────────────────────────────────┘
```

注記

- 説明はこの 1 画面だけ。チュートリアルの重ね表示（オーバーレイ）は作らない
- キーの行は PC だけに出す。タッチの端末では出さない
- 判定の 10 文は易しい順に出し、×の再出題はしない（`../decisions.md` 2026-09-22「初回の判定 10 文を初日の今日の分にする」）

### W3a 開始画面: 今日の分・未開始

登場フロー: F2 の 1 手目。2 日目以降、昨日の今日の分を終えている日にアプリを開くとここに来る。
この画面の役割: 今日やることを見せ、1 回押すだけで始めさせる。

```
┌──────────────────────────────────────────────┐
│ ♪                              記録   設定   │
│                                              │
│ 12                                           │
│ 日連続                                       │
│ 月  火  水  木  金  土  日                   │
│ ●   ●   ●   ●   ●   ·   ·                    │
│                                              │
│ 今日の分                                     │
│ 10 文 ・ 約 5 分                             │
│ 復習 4 ・ 新しい文 6 ・ 重点 会議            │
│                                              │
│                                              │
│                                              │
│ [              始める   Space              ] │
└──────────────────────────────────────────────┘
```

注記

- 選ぶものは置かない。「始める」か Space / Enter で始まる（`../decisions.md` 2026-09-22「今日の分は開始ボタンを 1 つ挟んで始める」）
- 「10 文 ・ 約 5 分」は既定の枚数での例。実際は「N 文 ・ 約 M 分」で、M は N × 30 秒を分に切り上げた値（5 → 3 分、10 → 5 分、15 → 8 分、20 → 10 分、30 → 15 分）。係数は変えられる形にする。×の再出題は含まない（`../decisions.md` 2026-09-22「枚数 5〜30 に合わせた画面の細部」）
- 「復習 4 ・ 新しい文 6 ・ 重点 会議」は配合の結果を見せるだけで、変えられない。重点が無いときは「重点」を出さない
- 週の並びはこの時点では今日の点が「これから」。今日の分を終えると `◎` になる（W3c）
- 昨日だけ空いていて一昨日まで連続があれば W3e、2 日以上空いていれば W3f になる（F2）
- 左上の `♪` で効果音を切り替える（既定はオン）。右上の「記録」「設定」は `button/text`
- 読み込みが 300ms を超えたら、ボタンと数字の位置だけの `skeleton` を出す（§4.7）

### W3a の変化形: 出せる文が設定の枚数より少ない日

登場フロー: F2 の 1 手目。出せる文が 5 文以上あり、設定の枚数に届かない日。

```
┌──────────────────────────────────────────────┐
│ ♪                              記録   設定   │
│                                              │
│ 12                                           │
│ 日連続                                       │
│ 月  火  水  木  金  土  日                   │
│ ●   ●   ●   ●   ●   ·   ·                    │
│                                              │
│ 今日の分                                     │
│ 7 文 ・ 約 4 分（設定 10）                   │
│ 点検済みの文が足りないため 7 文です          │
│ 復習 3 ・ 新しい文 4                         │
│                                              │
│ [              始める   Space              ] │
└──────────────────────────────────────────────┘
```

注記

- 「7 文 ・ 約 4 分（設定 10）」と出し、その下に 1 行「点検済みの文が足りないため 7 文です」を `text/secondary` で添える。この 7 文を終えれば今日の分は完了で、ストリークに数える（`../decisions.md` 2026-09-22「枚数 5〜30 に合わせた画面の細部」）
- 5 文未満なら W3d になる
- W3f（途切れた後）で文が足りない日も、下半分は同じ形になる

### W3b 開始画面: 今日の分・途中

登場フロー: F5 の再開。同じ日に、今日の分（または昨日の分）を途中で閉じた後に開くとここに来る。

```
┌──────────────────────────────────────────────┐
│ ♪                              記録   設定   │
│                                              │
│ 12                                           │
│ 日連続                                       │
│ 月  火  水  木  金  土  日                   │
│ ●   ●   ●   ●   ●   ·   ·                    │
│                                              │
│ 今日の分  途中                               │
│ 4 / 10 まで進んでいます                      │
│                                              │
│                                              │
│ [             続きから   Space             ] │
└──────────────────────────────────────────────┘
```

注記

- 「続きから」で、中断した文の表から再開する。その文の持ち時間は最初から数え直す（§5 の 3）
- 閉じている間に点検で残りのカードが削除されたり未点検に戻ったりしていたら、それを外し、同じ配合の規則で同じ枚数だけ補う。「4 / 10」の分母は変わらない（§5 の 14）
- 連続（コンボ）は 0 に戻る
- 昨日の分（F10）の途中なら、見出しは「昨日の分  途中」、上の連続の表示は W3e と同じ（一昨日までの連続、昨日の点は「取り返せる空き」）。W3e で「今日から数え直す」を選んだ日の今日の分の途中なら、上の表示は W3f と同じ（「今日から 1 日目」）
- 日の区切りを越えたら、この画面ではなく新しい今日の分の開始画面（W3a / W3e / W3f）になる。前日の残りは捨てる（F5）

### W3c 開始画面: 今日は完了

登場フロー: F2 の後、F6 の入口。今日の分を終えた日に開くとここに来る。

```
┌──────────────────────────────────────────────┐
│ ♪                              記録   設定   │
│                                              │
│ 13                                           │
│ 日連続                                       │
│ 月  火  水  木  金  土  日                   │
│ ●   ●   ●   ●   ●   ◎   ·                    │
│                                              │
│ 今日は完了                                   │
│ 今日 2 回 ・ 20 文                           │
│                                              │
│ (             今日の締めを見る             ) │
│ [            もう 10 文   Space            ] │
└──────────────────────────────────────────────┘
```

注記

- 主な操作は「もう 10 文」（文の数は設定の値）。今日の分は終わっているので、ここでは続けることを主にする
- 「今日の締めを見る」で、その日の最後の回の終わりの画面を読み返す（W9r、§5 の 18）。読み返すまでに点検で削除された文は、墓標の日本語で出す（`../decisions.md` 2026-09-22「削除・作り直しになったカードの『できた』は数え続け…」）
- 「今日 2 回 ・ 20 文」は今日の分・追加の回・昨日の分の回の合計（その日に実際にやった回）

### W3c の変化形: 昨日を取り返せる日

登場フロー: F10 の枝。W3e で「今日から数え直す」を選び、今日の分を終えた日に、日の区切り（午前 4 時）まで出る。

```
┌──────────────────────────────────────────────┐
│ ♪                              記録   設定   │
│                                              │
│ 1                                            │
│ 日連続                                       │
│ 月  火  水  木  金  土  日                   │
│ ●   ●   ●   ○   ◎   ·   ·                    │
│             空                               │
│                                              │
│ 今日は完了                                   │
│ 今日 1 回 ・ 10 文                           │
│ 昨日の分をやれば 14 日連続に戻ります         │
│ 午前 4 時まで                                │
│                                              │
│               今日の締めを見る               │
│ (                もう 10 文                ) │
│ [        昨日の分を取り返す   Space        ] │
└──────────────────────────────────────────────┘
```

注記

- 主な操作は「昨日の分を取り返す」（Space）。このときだけ「もう 10 文」は縁取り、「今日の締めを見る」は `button/text` になる（`../decisions.md` 2026-09-22「ストリークの週 1 回の猶予をやめ、1 日空いたら翌日に『昨日の分』を取り返せるようにする」）
- 連続は「1 日連続」。昨日の点は「取り返せる空き」（`○` と下に「空」）のまま
- 「昨日の分をやれば 14 日連続に戻ります」は、取り返したときの連続の数を出す（一昨日までの 12 + 昨日 + 今日）
- 取り返すと W9y（昨日の点が埋まり、連続が 1 → 14）→「終わる」で通常の W3c（14 日連続）に戻る
- 期限の「午前 4 時まで」を `caption`（`text/secondary`）で出す。日の区切りを越えたら出ない。取り返さなかった昨日の点は「未」になる
- 「今日 N 回 ・ N 文」には昨日の分の回も含める（今日やった練習なので。累計を実際の日で数えるのと同じ）

### W3d 開始画面: 出せる文が足りない

登場フロー: F2 の端の状態。
この画面の役割: 点検済みの文が足りず今日の分を組めないことを伝える。

```
┌──────────────────────────────────────────────┐
│ ♪                              記録   設定   │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │ 出せる文が足りません                     │ │
│ │ 点検済みの文が 3 文しかありません。      │ │
│ │ カードの生成と点検を実行してください     │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│ (            設定で範囲を広げる            ) │
└──────────────────────────────────────────────┘
```

注記

- 出せる文が 5 文以上あれば、ある分だけで今日の分を組み、「今日の分 7 文（設定 10）」と出して通常どおり進める（W3a の変化形）。組めた枚数を終えればストリークに数える。5 文未満のときだけこの画面になる（§5 の 7、§5 の 13）
- 「出せる文」は、選んだ大トピックの中で、点検済み（ハッシュが一致）で、今の難易度の範囲にある文
- 自分用の段階なので、生成と点検のスキルを実行するよう直接書く
- Esc では何もしない。開始画面なので戻る先がない（§5 の 22）

### W3e 開始画面: 昨日が空いた

登場フロー: F2 の分岐、F10 の 1 手目。今日の分を終えなかった日が昨日の 1 日だけで、一昨日までの連続が 1 以上あり、今日の分をまだ始めていないときに来る。
この画面の役割: 昨日の分を取り返すか、今日から数え直すかを選ばせる。

```
┌──────────────────────────────────────────────┐
│ ♪                              記録   設定   │
│                                              │
│ 12                                           │
│ 日連続                                       │
│ 昨日が空いています                           │
│ 月  火  水  木  金  土  日                   │
│ ●   ●   ●   ○   ·   ·   ·                    │
│             空                               │
│                                              │
│ 昨日の分もやれば連続が続きます               │
│ 午前 4 時まで                                │
│ 昨日の分 10 文 + 今日の分 10 文 ・ 約 10 分  │
│                                              │
│ (             今日から数え直す             ) │
│ [          昨日の分もやる   Space          ] │
└──────────────────────────────────────────────┘
```

注記

- 数字は一昨日までの連続（「12 日連続」）。その下に 1 行「昨日が空いています」（`../decisions.md` 2026-09-22「ストリークの週 1 回の猶予をやめ、1 日空いたら翌日に『昨日の分』を取り返せるようにする」）
- 週の点の昨日は「取り返せる空き」（`○`、下に「空」）
- 「昨日の分もやる」（Space、`button/primary`）: 昨日の分の回 → W9y → 「今日の分へ」で今日の分 → W9（F10）
- 「今日から数え直す」（`button/secondary`）: そのまま今日の分が始まる。連続は途切れた扱いで表示する（W3f と同じ「今日から 1 日目」）。日の区切りまでは、今日の分を終えた後の W3c で取り返せる
- 昨日の分は設定の枚数で、配合は今日の分と同じ規則。「約 10 分」は 2 回分の枚数（10 + 10）× 30 秒を分に切り上げた値
- 配合の内訳の行（W3a の「復習 4 ・ 新しい文 6」）は、2 回分になるのでこの画面では出さない
- 期限は今日の区切り（午前 4 時）で、「午前 4 時まで」を `caption`（`text/secondary`）で出す。回数の上限はない。初回（記録なし）には出ない（`../decisions.md` 2026-09-22「取り返しの端のケースと、設計の書き直しで当方が置いた細部」）
- 取り返した日は済みと同じ `●` で連続に数え、区別しない

### W3f 開始画面: 途切れた後

登場フロー: F2 の分岐、F5。2 日以上空いたとき（昨日も一昨日も今日の分を終えていない）、今日の分を終えるまでの開始画面。
この画面の役割: 0 を出さずに、今日から数え直すことを見せる。

```
┌──────────────────────────────────────────────┐
│ ♪                              記録   設定   │
│                                              │
│ 今日から 1 日目                              │
│ 最長 21 日                                   │
│ 月  火  水  木  金  土  日                   │
│ ●   ●   ─   ─   ·   ·   ·                    │
│                                              │
│ 今日の分                                     │
│ 10 文 ・ 約 5 分                             │
│ 復習 4 ・ 新しい文 6 ・ 重点 会議            │
│                                              │
│                                              │
│ [              始める   Space              ] │
└──────────────────────────────────────────────┘
```

注記

- 「0 日連続」を出さない。数字の代わりに「今日から 1 日目」、その下に小さく「最長 21 日」（`../decisions.md` 2026-09-22「途切れた回・成長しなかった回・全部言えた回は、大きな 0 を出さない」）
- 今日の分を終えれば W9 で「1 日連続」（数字は強調色）。W3c も「1 日連続」
- W3e で「今日から数え直す」を選んだ日の W3b も、この表示にする
- 途切れた日と、期限を過ぎた空きは「未」（`─`）
- 下半分（今日の分・配合・「始める」）は W3a と同じ

```

│ ┌──────────────────────────────────────────┐ │
```

  最初の画面の高さに「今日の成長」と「復習に回った文」が入るようにする
- 今日の成長: 復習で出た文を前回と比べる。「速くなった文」（めくるまでの秒数が前回より短い○）と「×→○」の数を大きく出し、

- 復習に回った文: ×と時間切れの文の数と一覧。×の数・正答率は出さない。再出題で言えた文も、後日の復習には回るのでここに並ぶ。
  一覧は 3 行までで、4 文目からは「すべて見る」にしまう。数は大きく出したまま（30 枚の日でも最初の画面の高さに収めるため、§5 の 15）。
  0 の回は一覧を出さず「復習に回った文 0」の 1 行だけにする（同上）
- 「すべて見る」はその場で下に開き、「閉じる」に変わる（変化形「すべて見るを開いた状態」、§5 の 16）
- ストリーク: 今日の分の回だけ数字が増え、今日の点が `◎` になる。追加の回では静止。途切れた後に今日の分を終えた回は「1 日連続」（W3f）
- 難易度: 上がった回だけ行が光る（`↑`）。下がった回は同じ文言に `↓`、光らない。変わらない回は行ごと出さない
- 到達度: 大トピックごとのリング。この回で増えた分だけ強調色で伸び、「+3」が付く。「次の節目まで」は一番近いものを 1 つだけ。
  節目は 10 / 25 / 50 / 100、以後 100 ごと（初期値。`../decisions.md` 2026-09-22「持ち時間・『速い』・節目・称号の初期値」）。例の 101 文はリングが 1 / 100、137 文は 37 / 100、58 文は 8 / 50。
  点検で削除されたカードの「できた」も数え続け、大トピックは墓標の値で数える（`../decisions.md` 2026-09-22「削除・作り直しになったカードの『できた』は数え続け…」）
- 到達度のリングは 3 つの `concentric` の例。大トピックは全部で 5 つで、5 つ全部を選ぶと `grid`（直径 72 の単独リングを 2 列 × 3 段、高さ約 250px）になる（`design-system.md`「到達度のリング」）
- 称号: 節目に達した回だけカードが出る。名前は数と対象だけ（「日常 100 文」「30 日連続」）で、全体の合計には称号を付けない（初期値、同上）。
  取った称号は、あとで数が節目を下回っても取り消さず、同じ称号は二度出さない（`../decisions.md` 2026-09-22「称号は取り消さず、同じ称号は二度出さない」）。
  1 回で複数に届いたら全部を縦に並べる（変化形「複数の称号」、§5 の 17）
- ポイント: この回の分と合計。やり切った回に枚数と同じ pt、今日の分（昨日の分を含む）を終えた回は +10。例の「+20 pt」は 10 枚の今日の分（`../decisions.md` 2026-09-22「ポイントは枚数 × 1 pt。今日の分（昨日の分を含む）を終えた回は +10」）。追加の回 10 枚なら「+10 pt」。
  累計は言った文と練習した日、直近 14 日の棒
- 動くのはこの回に変わった値だけ。変わらない値は最初から最終値で出す（`design-concept.md` 原則 1）
- 主な操作は「終わる」（Space）。「もう 10 文」は縁取り（§5 の 2）。右上の ✕ も「終わる」と同じ（読み上げは「閉じる」）
- 途中で「すべて見る」を開いても、ボタンの位置は画面の下に固定する
- 記録の保存が済んでいなければ、先頭に `inline-notice`「保存できていない記録が 2 件あります」+「送り直す」を出す（§4.6）

## 3. フロー

### F1 初回

```
[起動・記録なし] -> [W1 場面を選ぶ] -> [W2 説明] -> [W4 -> W5/W6] x 10（易しい順・再出題なし）
                                                          |
                                                          v
                                  [W9f 終わりの画面（判定の結果）] -> 終わる -> [W3c 今日は完了]
```

1. 初めて開くと W1。大トピックを 1 つ以上選び「次へ」
2. W2 で判定のしくみとキーを読み、「始める」
3. 易しい順に 10 文。1 枚ごとの流れは F3。×と時間切れの文は再出題せず、後日の復習に回る
4. W9f で判定の結果（難易度）と、通常の終わりの画面を見る。ストリーク 1 日目
5. 「終わる」で W3c。「もう 10 文」なら F6

### F2 今日の分

```
[開く・今日の分は未開始] --昨日は済み-------------------------> [W3a 開始画面]
          |--昨日だけ空き・一昨日まで 1 日以上の連続--> [W3e 昨日が空いた]（F10）
          |--2 日以上空いた--------------------------> [W3f 途切れた後]
          |--出せる文が 5 文未満---------------------> [W3d]

[W3a / W3f] -> 始める -> [F3] x N -> ×か時間切れがあった? --いいえ--> [W9]
                                               | はい
                                               v
                                   [W4r もう一度] x その数（F3 と同じ）-> [W9] -> 終わる -> [W3c]
```

1. 開くと、昨日の今日の分を終えていれば W3a。昨日だけ空いていて一昨日まで 1 日以上の連続があれば W3e（F10）、2 日以上空いていれば W3f。初回（記録なし）は F1
2. 「始める」か Space
3. N 文を F3 で進める。N は設定の枚数（既定 10）と出せる文の少ない方（§5 の 13）
4. ×と時間切れの文があれば、出た順にもう一度出す（F4）
5. W9 で締める。ストリークが 1 増える（W3f からなら「1 日連続」）
6. 「終わる」で W3c。「もう 10 文」なら F6

### F3 1 枚の中

```
[W4 表・計時開始] --めくる(Space/Enter/クリック)--> [W5 裏] --○(→/J)--> [W7 手応え] -> 次の W4
       |                                               \
       | 残り 0                                         --×(←/F)--> 次の W4
       v
[W6 裏・時間切れ・×を自動で記録] --次へ(Space)--> 次の W4
```

1. 表を描画した瞬間から計時する
2. 自分でめくると W5。めくるまでの秒数を記録する
3. ○を押すと W7 の手応え（最大 320ms）のあと、次の表へ。×を押すと手応えなしで次の表へ
4. 時間切れなら自動でめくれて W6。×は自動で記録。「次へ」で次の表へ
5. 最後の 1 枚の後は、F4（もう一度）か終わりの画面へ

### F4 ×の再出題

1. 通常の N 文を終えた時点で、×と時間切れの文を出た順に並べる
2. 1 枚ずつ W4r（`〔もう一度〕`）で出す。流れは F3 と同じで、時間切れもある
3. もう一度の結果も記録する。ただし同じ日の 2 回目の○なので、到達度（別の日に 2 回）には数えない
4. もう一度でも×か時間切れなら、後日の復習に回るだけで、それ以上は出さない
5. もう一度の文の○×は、終わりの画面の「今日の成長」の比較には使わない（その回の 1 回目の結果で比べる）

### F5 中断と再開

```
[W4/W5/W6] --Esc / ✕ 中断 / ページが隠れた--> [W8 シート（表を隠す・残り秒を止める）]
                                  |                     |
                            続ける(Esc)              いまはやめる / タブを閉じる
                                  |                     |
                     止めた残り秒から再開          [W3b 途中]（同じ日）
                                                        |
                                            続きから -> 中断した文の表（持ち時間は数え直す・連続は 0）

[日の区切りを越えて開く] --前日は済み--> [W3a]
          |--前日だけ空き・一昨日まで 1 日以上の連続--> [W3e]（F10）
          |--それ以外--> [W3f]
          （前日の残りは捨てる）
```

1. カードの画面で Esc か「✕ 中断」を押すと W8。表を隠し、残り秒を止める
2. タブの切り替えや画面のロックでページが隠れたとき（visibilitychange）も、自動で W8 を出して残り秒を止める。見えるように戻っても W8 のまま。別のアプリを前に出しただけ（ページが見えたまま）では止めない（`../decisions.md` 2026-09-22「ページが隠れたら中断する。回は始めた日に属する」）
3. 「続ける」で、止めた残り秒から再開する。連続は保つ
4. 「いまはやめる」かタブを閉じると、そこまでの記録を保存して W3b へ
5. 同じ日に開くと W3b。「続きから」で、中断した文から。持ち時間は最初から数え直し、連続は 0。
   残りのカードが点検で削除されたり未点検に戻ったりしていたら外し、同じ配合の規則で同じ枚数だけ補う（§5 の 14）。
   昨日の分（F10）の途中も同じ扱いで、W3b は「昨日の分  途中 4 / 10」
6. 日の区切りを越えて開くと、新しい今日の分の開始画面。前日を終えていれば W3a、前日だけ空いていて一昨日まで 1 日以上の連続があれば W3e、それ以外は W3f。前日の未回答の文は、次の配合の候補に戻る
7. 回の途中で日の区切りを越えても、その回は始めた日に属する（今日の分、ストリーク、到達度の「別の日」）（同上）
8. 日の区切りは午前 4 時（`../decisions.md` 2026-09-22「1 日の区切りは午前 4 時」）

### F6 追加の回

1. W9 か W3c で「もう 10 文」（文の数は設定の値）
2. 通常と同じ配合で次の N 文。流れは F2 の 2〜3 と同じ
3. W9 で締める。ストリークは動かず静止。この回で変わった値（成長、ポイント、累計、到達度、難易度）だけが動く
4. 「終わる」で W3c

### F7 設定を変える

1. W3 の「設定」から W11
2. 大トピック・重点・枚数・効果音を変える。その場で保存する
3. 枚数はその日の分にもすぐ反映する。途中の今日の分なら残りの枚数が変わり、すでに終えた枚数が新しい枚数以上なら「今日は完了」になる
4. 大トピックと重点は、今日の分をまだ始めていなければ今日の分から、途中なら次の回から効く
5. 「← 戻る」で W3

### F8 難易度を測り直す

1. W11 の「難易度を測り直す」
2. W12 で「測り直す」
3. W2（1 行目が「10 文で難易度を測り直します」）→ 易しい順に 10 文（F1 の 3 と同じ）
4. W9f。「次から TOEIC 730 前後の文」
5. 今日の分がまだだった日は、この 10 文を今日の分の 10 枚として数える。設定が 10 以下なら今日の分は完了し、ストリークが増える。
   10 を超えるなら W9f の「終わる」で W3b（「途中 10 / 20」）へ進み、残りを新しい難易度で続ける。終えていた日は追加の回と同じ扱い（§5 の 12）
6. 測り直しの 10 文は、昨日の分には数えない。W3e の日に測り直しても、今日の分（または追加の回）として数え、昨日は空きのまま（`../decisions.md` 2026-09-22「ストリークの週 1 回の猶予をやめ、1 日空いたら翌日に『昨日の分』を取り返せるようにする」）

### F9 記録を見る

1. W3 の「記録」から W10
2. 大トピックの行を開くと、サブトピックごとの横棒が出る
3. 「← 戻る」（Esc）で W3

### F10 昨日の分を取り返す

```
[W3e 昨日が空いた]
   |
   |--昨日の分もやる(Space)--> [昨日の分 F3 x N（+F4）] -> [W9y 昨日の分 完了]
   |                                                        |            |
   |                                            今日の分へ(Space)      終わる
   |                                                        |            |
   |                              [今日の分 F3 x N（+F4）] <-+            v
   |                                        |                   [W3a 13 日連続]
   |                                        v
   |                                [W9] -> 終わる -> [W3c]
   |
   |--今日から数え直す--> [今日の分 F3 x N（+F4）] -> [W9 1 日連続] -> 終わる
                                                                        |
                                                                        v
                                                    [W3c 昨日を取り返せる日]（午前 4 時まで）
                                                                        |
                                                  昨日の分を取り返す(Space)
                                                                        v
                               [昨日の分 F3 x N（+F4）] -> [W9y 連続 1 → 14] -> 終わる -> [W3c 14 日連続]
```

1. W3e で「昨日の分もやる」（Space）。昨日の分の回が始まる。枚数は設定の値、配合は今日の分と同じ規則。1 枚ごとの流れと再出題は F2 の 3〜4 と同じ
2. W9y で締める。昨日の点が埋まり、連続が 1 増える（どちらも強調色）。「もう N 文」は出さない
3. 「今日の分へ」（Space）で今日の分が始まり、F2 の 3〜6 と同じ。「終わる」なら W3a（今日の分はまだ）
4. W3e で「今日から数え直す」を選ぶと、そのまま今日の分が始まる。途切れた扱いの表示（W3f の「今日から 1 日目」）で、W9 は「1 日連続」
5. 日の区切り（午前 4 時）までは、W3c に「昨日の分を取り返す」が主な操作で出る。やると W9y（昨日の点が埋まり、連続が 1 → 14）。今日の分は済んでいるので W9y の主な操作は「終わる」で、W3c（14 日連続）に戻る
6. 中断と再開は今日の分と同じ（F5）。W3b は「昨日の分  途中 4 / 10」
7. 取り返した日は済みと同じ `●` で連続に数え、区別しない。ポイントは今日の分と同じ（枚数 × 1 pt + 10）。到達度の「別の日」と累計の「練習した日」は、実際にやった日（今日）で数える
8. 期限は今日の区切り。回数の上限はない。区切りを越えると昨日の点は「未」になり、連続は途切れる（次に開くと W3f）。区切りの前に始めた昨日の分の回は、途中で区切りを越えても始めた日に属する（F5 の 7）
9. 測り直しの 10 文は昨日の分に数えない（F8 の 6）。初回（記録なし）には W3e は出ない
10. 出せる文が足りない日は、昨日の分・今日の分とも、各回を始める時点で出せる文を数え直す。5 文以上なら「設定の枚数と出せる文の少ない方」で組み、5 文未満なら W3d（§5 の 13 と同じ規則）
11. W9y を出した時点で午前 4 時を越えていたら、「今日の分へ」は押した時点の日の今日の分を始める（回は始めた日に属する、F5 の 7）。昨日の分の回は始めた日に属するので、埋まるのはその日から見た昨日
12. 出典: `../decisions.md` 2026-09-22「ストリークの週 1 回の猶予をやめ、1 日空いたら翌日に『昨日の分』を取り返せるようにする」「取り返しの端のケースと、設計の書き直しで当方が置いた細部」

### 4.7 読み込みと手応え

- 今日の分（昨日の分も）の N 文と、もう一度に使う裏の中身は「始める」の時点でまとめて読み込む。カードの間で読み込み待ちを出さない（計時が歪むため）
- 開始画面の読み込みが 300ms を超えたら、ボタンと数字の位置だけの骨組み（`skeleton`）を出す。回る印（スピナー）は使わない
- 成功のトーストは出さない。記録の保存が成功したことは知らせない（手応えは○の光と終わりの画面で足りている）

### 4.8 アクセシビリティ

`design-system.md`「アクセシビリティ」のとおり。画面ごとの補足だけをここに書く。

- W3a〜W3f の `♪`: 「効果音 オン」「効果音 オフ」と読み上げ、`aria-pressed` で状態を伝える。オフのときは ♪ に斜線を入れる（色だけで示さない）
- W3e: 数字の後に「昨日が空いています」を読む。昨日の点は「空」の文字でも伝える
- W3f: 「今日から 1 日目。最長 21 日」と読む。「0 日連続」とは読ませない
- W4〜W6: 表を出したら「表。〈日本語〉。持ち時間 8 秒」、時間切れで「時間切れ。復習へ」を読み上げる。`✕` は「中断」と読み上げる
- W5 / W6: 裏がカードに収まらないとき、カードの中のスクロール領域にフォーカスを置けるようにし、↑ / ↓ で動かす
- W8: シートが出たらフォーカスをシートの中に閉じ込め、「続ける」に置く。ページが隠れて出たときも、戻ったときに「続ける」にフォーカスがある
- W9 / W9y: 見出し（「今日は完了」「昨日の分 完了」）にフォーカスを置く。数え上げの途中の値は読み上げず、最終値だけを読む。称号が複数なら出す順に読む。`✕` は「閉じる」と読み上げる
- W9 の「すべて見る」: `aria-expanded` で開閉を伝える。開くと「閉じる」に変わり、フォーカスはそのボタンに残る
- W9r: 見出し「今日の締め」にフォーカスを置く。Esc で戻る
- W10: 大トピックの内訳の開閉（`disclosure`）は `aria-expanded` で伝える
- W11: 重点の上限で押せなくなったチップは、押せない理由（「重点は 2 つまで」）を読み上げる

当方が案として置き、2026-09-22 にオーナーが了承したもの。原典は `../decisions.md`。

1. 1 日の区切りは午前 4 時（「1 日の区切りは午前 4 時」）
2. 終わりの画面の主な操作は「終わる」、「もう 10 文」は縁取り。完了後の開始画面（W3c）では「もう 10 文」を主にする（「終わりの画面の主な操作は『終わる』」）。昨日を取り返せる日の W3c だけは「昨日の分を取り返す」を主にする（A）
3. 途中で閉じて同じ日に再開したら、中断した文から。持ち時間は最初から数え直し、連続は 0（「途中で閉じた今日の分は、中断した文から持ち時間を数え直して再開する」）
4. 中断のシートの間は表を隠し、残り秒を止める。「続ける」で止めた残り秒から再開し、連続は保つ（以下 4〜10 は「ワイヤーの細部」）
5. 判定の測り直しは、今日の分がまだならそれを今日の分とし、終えていれば追加の回と同じ扱い。昨日の分には数えない（A）
6. 開始画面に配合の内訳（「復習 4 ・ 新しい文 6 ・ 重点 会議」）を出す
7. 出せる文が 5 文以上なら、ある分だけで今日の分を組む。5 文未満のときだけ W3d
8. もう一度の文の結果は、今日の成長の比較にも到達度にも使わない
9. 裏を出してから 150ms は○×のキーを受け付けない
10. 記録の保存に失敗しても練習は止めず、次の回答のときに送り直す

枚数（5 / 10 / 15 / 20 / 30、既定 10、すぐ反映）は別のセッションで決まった（「今日の分の枚数を自分で決められるようにする」）。
このワイヤーの「10 文」「もう 10 文」は既定の枚数での例示で、実際には設定の枚数が入る。

11〜15 は、枚数と生成・点検の決定をこのワイヤーと突き合わせたときに決めたもの（「枚数 5〜30 に合わせた画面の細部」）。

11. 開始画面の目安の時間は、枚数 × 30 秒を分に切り上げて出す。係数は変えられる形にする
12. 測り直しを今日の分として数える日は、10 文を今日の分の 10 枚として数える。設定が 10 を超えるなら W9f の後に W3b から残りを続ける
13. 出せる文が設定の枚数より少ない日（5 文以上）は、今日の分をその枚数で組み、終えればストリークに数える
14. 同じ日に再開したとき、残りのカードが削除・未点検になっていたら外し、同じ枚数だけ補う
15. 終わりの画面の「復習に回った文」は 3 行まで。残りは「すべて見る」

点検で削除されたカードの記録の扱い（到達度には数え続け、出題・復習・今日の成長の比較からは外す）と称号の扱い（取り消さず、二度出さない）は、
「削除・作り直しになったカードの『できた』は数え続け…」「称号は取り消さず、同じ称号は二度出さない」。

16〜22 は、画面の細部として決めたもの（「画面の細部（すべて見る・複数の称号・締めの読み返し・裏のスクロール・記録の空の状態・部品・Esc）」）。

16. 「すべて見る」はその場で下に開く（別画面にしない）。開くと「閉じる」に変わる。30 枚の日で最大 30 行。行は押せない（裏は出さない）。ボタンは画面の下に固定のまま（W9 の変化形「すべて見るを開いた状態」）
17. 1 回で複数の称号に届いたら、称号のカードを全部縦に並べる。順は連続 → 大トピックの一覧の順。150ms ずつずらして出す（W9 の変化形「複数の称号」）
18. 「今日の締めを見る」の W9 は W9r とし、見出し「今日の締め」と左上に「← 戻る」。下のボタンは出さない。数え上げなしで、その回に増えた値の強調色は残す
19. 裏が 1 画面に収まらないときは、カードの中だけを縦にスクロールする。上端の帯と○×（または「次へ」）は固定。下端 24px を `surface` へフェードする（装飾）。↑ / ↓ でカードの中をスクロールする（← / → は○×なので使わない）。
    見積もり: Lv10 の上限 28 語の模範解答（`answer` 22px、本文幅 340px で約 6 行）+ 同じ長さの別解 3 つ（`alt` 16px で各約 4 行）で、カードは約 730px、画面全体で約 880px。PC の縦に大きい窓では収まることが多く、スマホでは収まらない。語数の上限はプロダクト側 `content/levels.json`（Lv1 8 語 〜 Lv10 28 語）
20. 記録（W10）の空の状態: リングは溝だけ + 「別の日に 2 回言えた文がここに数えられます」。称号 0 は「まだありません」。称号が増えたら「連続」「日常」… の行に分け、取った節目の数を横に並べる（「連続 7・14・30」）（W10 の変化形「空の状態」）
21. 部品表（`design-system.md` §1）に `chip/choice`・`disclosure`・`bar-list`・`dot-calendar`・`milestone-list`・`icon-button`・`skeleton`・`inline-notice` を足し、値は既存のトークンだけで組む。`week-row` の状態も A に合わせて直す
22. Esc: W10・W11・W9r では「戻る」、W12 では「やめる」。W3d は開始画面で戻る先がないので、Esc では何もしない（当初の案の「W3d で戻る」は誤りで、「取り返しの端のケースと、設計の書き直しで当方が置いた細部」で訂正）。♪ は「効果音 オン」「効果音 オフ」と読み上げ（`aria-pressed`）、オフのときは ♪ に斜線を入れる。✕ は画面により「中断」「閉じる」と読み上げる。「すべて見る」は `aria-expanded`

同じ日に決まった体験の決定のうち、このワイヤーに効いたもの（見出しは `../decisions.md`）:

- A「ストリークの週 1 回の猶予をやめ、1 日空いたら翌日に『昨日の分』を取り返せるようにする」: 猶予の表示（「今週の休み あと n 回」「休」、W10 の「週 1 回までは休んでも続く」）を消した。W3e・W9y・F10、W3c の変化形（昨日を取り返せる日）、W3b の「昨日の分  途中」、F2・F5・F8、週の点の `○` の意味（取り返せる空き）
- B「途切れた回・成長しなかった回・全部言えた回は、大きな 0 を出さない」: W3f、W9 の変化形（成長も復習も 0 の回）、W9 の成長が混ざった回の「初めての 6 文」
- C「持ち時間・『速い』・節目・称号の初期値」: W9 の到達度と称号の例（節目 10 / 25 / 50 / 100、以後 100 ごと。称号名「日常 100 文」「14 日連続」）、W10 の称号の一覧。持ち時間と「速い」の値は `design-system.md`
- D「ポイントは枚数 × 1 pt。今日の分（昨日の分を含む）を終えた回は +10」: W9 の「+20 pt」、W9y・W9f のポイント
- E「ページが隠れたら中断する。回は始めた日に属する」: W8、F5 の 2 と 7、§4.1、§4.2、§4.3
- F「画面の細部（すべて見る・複数の称号・締めの読み返し・裏のスクロール・記録の空の状態・部品・Esc）」: 上の 16〜22

持ち時間の式、「速い」の閾値、到達度とストリークの節目、称号の名前は初期値が決まった（C）。どれも実装側で変えられる形にし、試しながら変える。
