# 難易度の段階に添える目安スコア（TOEIC・CEFR・IELTS・TOEFL）

- 調査日: 2026-09-22
- 調査手段: メインセッションによる検索と原典の確認（ETS の PDF は本文を抽出して確認）
- 問い: カードの難易度を TOEIC の点数で目安づけし、CEFR・IELTS・TOEFL の目安も並べるとき、各試験のどの公式の対応を下敷きにできるか

## 結論

- TOEIC L&R と CEFR には ETS の公式の対応表がある。合計の下限は A1 120 / A2 225 / B1 550 / B2 785 / C1 945。ETS 自身が「下限の目安で、厳密に使うことは勧めない」と書いている。
- 日本の TOEIC の目安としては、IIBC のレベル区分（A 860〜、B 730〜、C 470〜、D 220〜）が定番。730 と 860 は日本でよく目標にされる点数でもある。
- IELTS と CEFR の対応は、B1 4.0〜5.0 / B2 5.5〜6.5 / C1 7.0〜8.0 / C2 8.5〜（検索結果の要約。公式ページ本文は図のため数値を直接読めず、確度は中）。
- TOEFL iBT は 2026-01-21 から 1〜6 の尺度に変わり、CEFR に直接そろえた（3〜3.5 が B1、4〜4.5 が B2、5〜5.5 が C1）。
- これらはどれも「試験の点数と CEFR」の対応であり、**瞬間英作文の 1 文の難しさとの対応を示す資料はない**。カードの難易度表は、これらを下敷きにした自称の目安である（オーナーも「目安でよい、アプリ内の共通指標」と明言、2026-09-22）。

## 根拠

- 事実: TOEIC L&R の CEFR 下限。合計 120 / 225 / 550 / 785 / 945 点（A1〜C1）。Listening 60 / 110 / 275 / 400 / 490、Reading 60 / 115 / 275 / 385 / 455。「guidelines for minimum thresholds」「ETS does not recommend to use the minimum cut scores strictly」。A1〜B1 には TOEIC Bridge を勧めている。元の研究は Tannenbaum & Wylie（2006）
  - URL: https://www.eu.ets.org/content/dam/ets-org/eu/pdfs/toeic/mapping-cefr-toeic-listening-reading-test.pdf
  - 出典日付: 記載は「Copyright © 2025 by ETS Global」
  - 確度: 高（PDF 本文を抽出して数値を確認）
- 事実: IIBC のレベル区分 A〜E（860 以上 / 730〜860 / 470〜730 / 220〜470 / 220 以下）
  - URL: https://www.iibc-global.org/hubfs/library/default/toeic/official_data/lr/pdf/proficiency.pdf （検索結果での確認。本文は開いていない）
  - 出典日付: 記載なし
  - 確度: 中（検索結果の要約と、複数の二次情報が一致）
- 事実: TOEFL iBT の 1〜6 の尺度と CEFR の対応（6 = C2、5〜5.5 = C1、4〜4.5 = B2、3〜3.5 = B1、2〜2.5 = A2、1〜1.5 = A1）。旧尺度との対応は 5 ≈ 95 以上、4.5 ≈ 86 以上、4 ≈ 72 以上。IELTS との比較の例は IELTS 7 ≈ 合計 5、IELTS 6 ≈ 合計 4
  - URL: https://www.ets.org/toefl/institutions/ibt/score-scale-update.html
  - 出典日付: 記載なし（2026-01-21 からの変更）
  - 確度: 高
- 事実: IELTS と CEFR の対応。公式ページは「厳密な同等性を主張するものではない」とし、Band 5 は B1 とも B2 とも、6.5 は C1 の境目にまたがると書く
  - URL: https://ielts.org/organisations/ielts-for-organisations/compare-ielts/ielts-and-the-cefr
  - 出典日付: 記載なし
  - 確度: 中（注意書きは本文で確認。数値の帯は図のため、検索結果の要約に頼った）

## グレーゾーン・未確認

- TOEIC L&R は聞く・読むの試験で、話す・書くの力は測らない。「TOEIC 730 の人が瞬時に言える文」との対応は、どの出典にもない。
- TOEIC は 990 が上限なので、「990+」の段階は試験の外にある。
- CEFR の +/−（B1+ など）は、この表のための独自の刻み（オーナーの了承、2026-09-22）。CEFR の Companion Volume にも「plus levels」の考え方はあるが、ここでは照合していない。
- 段階ごとに割り当てた文法（中 1 相当など）は、日本の学校文法の一般的な順序にもとづく当方の案で、出典はない。
