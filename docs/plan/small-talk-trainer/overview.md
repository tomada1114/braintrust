# small-talk-trainer

## 一言で

Small Talk を英語で続けられるようになるための、ローカルで動かす英語チャット練習アプリ。

## 出発点

「Small Talk で会話を英語で続けられるようになりたい」という owner の課題から始まった。当初は Claude Agent SDK を使うことを想定していた。

既製品(ChatGPT / Claude アプリの音声モード)には次のような不満があった。

- 思った通りに動かない
- 一回の会話が長すぎる
- スコア・ゴール・ロードマップがないと学習が続かない
- 自分の引き出しの中からしか英語が出せない
- 全部を自分で打ち込むのは初心者にはハードルが高い
- まだ言語化できていない不満が他にもあるはず(継続的に拾っていく対象として open-questions.md に記録)

動機としては他に、会話後の振り返り・添削、練習の設計(ドリル・シナリオ)、作ること自体が目的(Agent SDK の学習)も挙がっていたが、Agent SDK への依存を避ける方針(decisions.md 参照)になったことで、最後の「学習目的」の比重は下がった。

## 既製品に無くて欲しいもの

上記の不満(思った通りに動かない・長すぎる・スコア/ゴール/ロードマップの不在・自分の引き出しの外に出られない・打ち込みのハードル)を解消する練習環境。

## 核の言い換え

(Claude の指摘、owner が「合っている」と確認)

作るのは「英語で話せる AI」ではなく「練習を短く区切り、次にやることを決め、自分の引き出しの外の表現を差し出す練習装置」。会話は手段であって目的ではない。

## 最初の版の範囲

- 短いセッション(場面の達成条件で終わる)
- 候補付き入力(レベル別 2〜3 個の候補から選び、自分の言葉で言い直して送る)
- 会話後の振り返り・添削(コーチ)
- 場面は AI 任せでランダム、または過去の会話・シナリオを踏まえてある程度ランダムに候補から選ぶ

スコア・ロードマップは第 2 版以降(モチベーションのために欲しいが最初からは要らない)。シナリオ・ドリルのライブラリも最初からは持たない。

## 作らないという選択肢

既製品(ChatGPT / Claude アプリ)の音声モードをそのまま使う。却下ではなく比較対象として残す。既製品に無い点は上の「既製品に無くて欲しいもの」の節の通り。
