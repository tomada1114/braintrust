# 個人・少人数開発の英語学習アプリ／SaaS の収益化実績

- 調査日: 2026-09-14
- 調査手段: Sonnet サブエージェント 3 体（並列・WebSearch / WebFetch のみ）+ メインセッションによる原典確認（Duolingo Q2 FY2026 の SEC 10-Q を直接フェッチして裏取り）
- 問い: 個人または少人数で作られた英語学習（語学学習全般）アプリ／SaaS で、実際に収益化に成功した事例はどれくらいあるか。その事例はどうやってユーザーを獲得したか。収益規模はいくらか。

## 結論

事例は「見つかった」が、**ほぼ全件が自己申告・確度低**で、かつ「収益規模」と「獲得経路」の両方を具体的な数字・原文引用つきで裏付けられた事例は、調査した 13 件中 **実質 1〜2 件**（Gliglish、Englister）にとどまる。それ以外は「収益規模は開示されているが獲得経路が不明」「獲得経路は分かるが収益規模が不明」「どちらも不明だがチームが小さいことだけは確認できた」のいずれかで、「セルフサーブ課金で安定的に月数十万円規模を継続している個人開発の語学アプリ」は、今回のデスクリサーチの範囲では**見つからなかった**。

判明した範囲で言えることは以下の通り。

1. 個人開発の語学アプリが実際に収益を得た例は複数実在するが、その規模はほとんどが「生活を支えるサブスク事業」ではなく「サイドプロジェクトの副収入〜赤字ギリギリ」の水準（例: Polygloss は3年運営してMRR $100未満、AtoZ Dictionaryは広告収益「うまい棒数本」、スペルキング.Jrは初の年間契約1件¥2,400）。
2. 例外的に大きな自己申告数字（Gliglish の MRR €3,000〜8,000、Live Linguaの年商$1.44M、Englister DAOの年間利益230万円）が見つかったが、いずれも第三者検証がなく、後者2件はビジネスモデルが「アプリの月額課金」とは異なる（Live Linguaはオンライン家庭教師マッチング、Englisterは暗号資産トレジャリーを持つDAO）。
3. 獲得経路として原文引用つきで確認できたのは、**Hacker News 投稿によるバズ（Gliglish）**と**Qiita記事のバズ＋Gigazine掲載（Englister）**の2件が突出しており、他は「Xでの継続発信」「TikTok投稿」など施策の言及はあっても効果の定量データがない。
4. 失敗・撤退事例（EnglisterDAO、ANQ、HideOut）からは、「作った本人が自分の語学アプリを使い続けたいと思えなかった」「グロースループ（紹介・口コミの自然発生）が組み込まれていなかった」「ピボットを繰り返すうちにコンセプトが薄まった」という共通パターンが読み取れる。
5. AI（ChatGPT音声モード等）の普及後も、専業AI英会話アプリ（Speak, Praktika, ELSA, Loora等）は2024年後半〜2025年にかけて大型資金調達を継続しており、少なくとも資金調達の面では「ChatGPTに駆逐された」形跡は見当たらない。ただし独立系アナリストによる定量的な影響分析（ダウンロード数減少など）は見つからなかった。

## 獲得経路の分布

原文引用つきで「主な獲得経路」を具体的に語れたのは13件中4件のみ（Gliglish, Englister, AtoZ Dictionary, Speak On./スペルキング.Jr は施策の言及のみで効果不明）。残り9件は「獲得経路の一次証言が見つからなかった」。この母数の小ささ自体が重要な発見であり、集計は参考値として扱うこと。

| 経路 | 該当件数（強い証拠つき） | 内容 |
|---|---|---|
| 開発者/技術者コミュニティでのバズ（Hacker News, Qiita） | 2件（Gliglish, Englister） | 唯一「原文引用＋定量的な初速データ」が揃っている経路。Gliglishは「Hacker Newsに投稿したら人々が話題にし始めた」、Englisterは「Qiita記事がバズり1000LGTM・Gigazineに掲載」と明言。ただし**どちらも「一度きりのバズ」に依存しており再現性の設計・継続的な流入経路にはなっていない**（Gliglishのインド由来トラフィックは「購入に繋がらないvanityだった」と本人が振り返っている） |
| SNS上の継続発信（X, TikTok） | 2件（施策の言及のみ、効果不明: Speak On., スペルキング.Jr） | 「ハッシュタグで毎日発信」「TikTokに投稿」という**施策自体は複数の事例で言及されるが、それが実際にどれだけの新規ユーザーをもたらしたかを示す数字は今回どの事例でも開示されていない** |
| ロコミ・オーガニックな地域拡散 | 1件（AtoZ Dictionary、米国での「プチバズり」） | 経路の内部構造（誰が最初に広めたか）までは特定できず |
| 価格戦略による質的フィルタリング | 1件（AnkiMobile、獲得"経路"ではなく価格設計による自己選別） | 新規流入チャネルの開拓ではなく、購入者の質を上げる戦略。参考として記録 |
| 不明・出典なし | 8件（Polygloss, Renshuu, WaniKani, Migaku, Bunpro, Live Lingua, Japanese Kanji Study, 他） | 「収益は自己申告であるが獲得経路は一次資料が見つからなかった」が最多パターン |

**読み取れること**: SEO（コンテンツ流入）を主要チャネルとして明言した事例は、今回の13件の中には1件もなかった（別ファイル `research/acquisition-channels.md` のSERP実測でも、個人が新規にSEOで上位を取るのは構造的に厳しいと結論づけている）。強い証拠がある2件はいずれも「開発者/技術者コミュニティ内でのオーガニックなバズ」であり、これは**再現性の低い一過性のイベント**（本人も「バズ後何もしなくても数千人来たが持続しなかった」という趣旨のニュアンスを残している）である点に注意が必要。「最初の100人・1000人をどう取ったか」を明快に答えられる個人開発の語学アプリ事例は、期待したほど多く見つからなかった。

## 失敗・撤退事例

### EnglisterDAO（Englister）

Qiita記事のバズで急成長した英作文添削サービスを、その後「DAO」（トークン報酬制のコミュニティ運営）に移行したが、約1年で解散。本人による解散理由（原文引用）:

> 「貢献数は9月をピークに減少し続けていました」「参加するメンバーが固定化してきました」「Englisterのサービスそのものへの貢献はほぼなく」「売上やユニークユーザ数も減少傾向」「貢献しても報われない場になってしまいました」

運営コストについても「毎週欠かさず定例会議を行なっていました」「DAOとしてのモメンタムが失われつつある中でこのような運営コストがしんどくなってきました」と説明。利益を全て暗号資産に変換してトレジャリーに入金していたため税務処理も困難だったと言及。出典: [Qiita 解散記事](https://qiita.com/yuno_miyako/items/ad61124bfef8becc4594)（2023-04-02、確度: 高）。

### ANQ（語学学習アプリ→AIパートナーサービスへピボット）

当初は韓国語・英語・中国語の語学学習アプリだったが、開発者自身が「自分が、自分のサービスを使っていない。作ってはいるけど、使いたいと思わない。」と気づき、AI彼氏・彼女的なAIコンパニオンサービスへ方向転換した。語学学習版のユーザー数・収益の開示はなし。出典: [note.com](https://note.com/anqapp/n/nb205cff10485)（2026-05-24、確度: 中 — ピボットの事実と動機は明確だが、「市場に見放された」のか「開発者が先に興味を失った」のかは本人の語りだけでは区別できない）。

### HideOut（英語シャドーイングアプリ→知識共有アプリへピボット→未使用のまま終息）

当初は英語シャドーイング練習アプリとして構想されたが、開発途中で方向性が変化し、最終的にはほぼ使われないまま終息。開発者の振り返り（原文引用）:

> 「アイデアや届けたい価値が曖昧になってしまっていた」「ゆっくり時間をかけてしまったことでそれが『今』では無くなってしまいました」

匿名マッチング機能を中心に据えたためユーザーが知人に紹介する自然な成長経路が生まれず、リリース前に機能を追加しすぎてコアの価値提案が薄まったとも振り返っている。出典: [Zenn](https://zenn.dev/masa_tokyo/articles/reflection-of-hideout)（2024-11-26、確度: 中）。**注意**: 失敗した最終形はすでに語学学習アプリではなく、知識共有アプリのピボット失敗という側面が強い。

### （参考）Polygloss

正式な post-mortem 記事ではないが、3年運営してMRR $100未満、サイトも現在は死んでいるという点で実質的な撤退事例。「うまくいかなかった」ことを示す率直な自己開示として参考になる（詳細は上表）。

### 探したが見つからなかったもの

英語圏（Indie Hackers, Reddit r/SaaS, Hacker News）での「語学学習アプリに特化した、創業者自身によるpost-mortem」は、今回のWebSearchクォータ制約の範囲内では見つからなかった。Duolingoの Tinycards 終了のような大手企業の一機能終了事例は存在するが、「個人・少人数」という条件に合わないため対象外とした。**この点は調査range の限界であり、「英語圏には失敗事例が少ない」ことの証明にはならない**。

## 個人がこの市場でセルフサーブ課金を成立させられるかの判定

**確度: 中**。「個人がセルフサーブ課金の語学学習アプリを作って何らかの収益を得ること」自体は、スペルキング.Jr（年間契約1件）からGliglish（自己申告MRR数千ユーロ）まで実例の幅として明確に可能だが、「生活を支えられる規模（月数十万円以上を継続的に）まで到達した、第三者検証つきの個人開発事例」は今回の調査では1件も確認できなかった。獲得経路として再現性高く機能したと言えるのはHacker News/Qiitaのような開発者コミュニティでの一度きりのバズであり、これは狙って起こせるものではなく、起きても持続的な流入には直結しない（Gliglish自身が「バズ後のトラフィックの一部はvanityで購入に繋がらなかった」と振り返っている）。SEOはビッグキーワードでは大手占有、ロングテールでも近年のAI Overviews/ゼロクリック検索の拡大で期待値が下がっている（`acquisition-channels.md`参照）。専業AI英会話スタートアップ（Speak, Praktika, ELSA等）が数十億円規模の資金調達を背景に同じ市場で競争を続けている以上、個人が汎用的な「英会話練習アプリ」で正面から戦うのは不利が大きい。一方で、ニッチな切り口（特定の学習者層、特定の言語ペア、特定の出題形式など）かつ最初から高い期待値を持たずに小さく始める前提であれば、今回見つかった複数の小規模事例（月数百円〜数千円規模の収益）程度は狙える可能性が高い、というのが現時点の判定である。
