# english-vocab-app

目的別の英単語アプリ。意味が分かる語を、自分の文で使える状態まで持っていく。
最初の版はお試しとして IELTS に限定し、将来 TOEFL や TOEIC など他の目的へ広げる。

## 誰の何の困りごとか

- 対象: 試験のために英単語を覚えようとして、続かずに何度も離脱してきた学習者。
  最初の版では IELTS 受験者。まずオーナー自身がこの層で、Overall 6.5、体感 6.0。
- 困りごと（2026-09-07 のヒアリングで観測された事実）:
  - **産出側が苦しい。** 受容側も困るが、Writing / Speaking で語が出てこないほうが苦しい。
  - **続かない。数日でやめる。**
  - **覚えたはずなのに使えない。**
  - **訳や例文が薄い、または不自然。**
  - **詰め込み感が強く、覚えること自体が辛くてモチベーションが上がらない。**
  - **単語だけを覚えても「マッピング」ができない。** 文脈から切り離された語は定着しない。
  - 学習曲線のようなものを取り入れられるとよい、という要望。

## 実在する痛みか

一人称の痛みであり、代替手段を 3 系統試してすべて離脱した履歴がある。離脱理由は系統ごとに違う。

- **mikan / abceed 系**: 「単語と意味だけなので、使える実感がない」
- **Anki / Quizlet などのカード型**: 「自分で作るのがあれすぎて」。素材作成コストで脱落
- **書籍の単語帳**: 「進捗管理とか、そもそも記憶テストとかもできないから進捗の実感がわかないし、達成感もないし、続かなかった」

代替手段で我慢できている状態ではない。
ただし、この痛みが試験受験者一般にどれだけ広く存在するかは未検証。
ユーザーニーズ調査は着手したが中断しており、成果物はない。

## 既存プロダクトとの違い

- 既存: 8 製品を調査した（`research/competitors/`）。mikan と abceed は意味当てで止まる。
  Anki と Quizlet は素材作成をユーザーに負わせる。iKnow! の Sentence Trainer は既存例文の
  再現練習。Vocabulary.com は選択式と穴埋め。WordUp は使い方の確認まで。
  IELTS 特化の直接競合 WordSprint は同義語セットという「材料」の提供まで。
- 差分: **自分の意見・自分の文で語を使う自由記述の産出練習を、8 製品のいずれも持っていない。**
  ここを埋める。ただし差別化のためだけの独自機構は作らない方針
  （`decisions.md` 第 2 部 2026-09-07 出題の決定）。

## 何を作るか（現時点の像）

- 形態: 未決。
- 中核の体験: 場面と候補語群から語を選び、即座に正誤が返り、確定した語で自分の文を書く。
  LLM が添削と講評を返す。詳細は `experience.md`。
- 語彙データ: **アプリに同梱する。** LLM 生成のみで作り、既存の公開リストは使わない。
  目的は語のレコード上の属性として持つため、最初の版で IELTS だけを収録しても、
  後から TOEFL などを足すのにスキーマを変える必要がない。
  **将来ライブラリとして切り出せるよう、アプリのロジックから切り離せる形で置く。**
- AI の位置づけ: 語彙データの生成と、書いた文への添削・講評。実行時の添削は LLM 必須。

## 語彙データについて分かっていること

`research/` の調査 5 本で、次のことが確定している。

- 無料かつ商用アプリに組み込めるレベル別語彙リストは実在する。
  CEFR-J が A1〜B2 で 7,801 語、Octanove が C1〜C2 で 2,136 語、NGSL ファミリーが目的別を埋める。
  **ただしオーナーはこれらを使わず LLM 生成のみで作ると決めている。**
- **IELTS・TOEFL・TOEIC・英検・GTEC のいずれにも、試験実施団体が公表した公式語彙リストは存在しない。**
  つまり「IELTS 7.0 相当の語」は誰が作っても自称になる。
- Cambridge / Oxford / Pearson / Council of Europe のリストは無料で見られるが商用配布はできない。
- 語の同一性のキーは見出し語 + 品詞が実証済みの粒度。CEFR-J は 6,868 の見出し語のうち
  848 が品詞違いで複数行に分かれている。

## 作らない選択肢

作らなければ、オーナーは既存アプリのいずれかに戻るか、単語学習を続けない。
過去 3 系統すべてで離脱している以上、後者になる可能性が高い。
単語アプリは飽和した市場だが、競合調査の結果、自由記述の産出練習という空白は実在した。
一方でその空白が空いているのは、**添削のコストと正誤判定の難しさが理由かもしれない**。
そこが崩れるなら、作らない選択肢が正しくなる。
