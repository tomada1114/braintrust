## フィードバックの「決まった形式」の中身

- 何が決まれば決まるか: 何を評価軸にするか（構成、文法、自然さ、長さ、テンプレートに沿っているか など）、どの粒度か。
- 材料: オーナーの現時点の意向は「固定 3 項目（伝わるか＝構成、直すべき 1〜2 箇所、レベル相応の言い直し）+ 文法・語法の指摘 + 段階評価、全部入りが嬉しい」。未決の核心は段階評価（スコア）を入れるかどうか。懸念: LLM の採点はぶれるので数字が信用できず、上達の物差しとして質を選んだ決定とも整合しにくい。加えて `research/competitors/langua.md`、`research/competitors/chatgpt.md`。Langua は発言単位（訂正モード 5 択）＋会話後（6 往復以上でレポート）の二層構造だが、実際のレポート形式は一次観察でも未到達。ChatGPT は指定プロンプトで (1) 伝わるか (2) 直すべき箇所 (3) レベル別の言い直し (4) 文法・語法メモ、という 4 項目形式を 2 ターン維持できた。
- 材料（追記 2026-09-07）: 出力は JSON Schema で固定し UI が描画すると決定（decisions.md 2026-09-07）。フィールドは 伝わるか / 直すべき 1〜2 箇所 / レベル相応の言い直し / 文法・語法の指摘。残るのは各フィールドの粒度（指摘の件数上限、言い直しの長さ、説明の深さ）
- 状態: 一部決定済み（形式と枠は決定。粒度は未決。実装側で試して詰める候補）
