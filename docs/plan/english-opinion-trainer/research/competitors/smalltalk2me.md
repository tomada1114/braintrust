## 中核の体験（初回ユーザーの流れ）

メインセッションが公式ページで確認した中核ループ（2026-09-07）: 「take a speaking test → receive feedback → select a learning path → practice daily with AI → track progress」。公式トップページが示すオンボーディングはより細かく 5 ステップに分解できる。

1. 無料アカウントを作成する。
2. スピーキングテスト（English Level Test）を受ける — AI が CEFR レベル（A1–C2）を 15 分以内に判定すると謳う（「95% CEFR English level accuracy」）。
3. 学習目標を選ぶ（雑談 / IELTS / 面接 など）。
4. AI と毎日練習する（Speaking practice、shadowing、listening、quiz などのモード）。
5. ダッシュボードで進捗を確認する。

（URL: https://smalltalk2.me/ / 出典日付: 記載なし / 確度: 中）

## 主要機能

- English Level Test: CEFR (A1–C2) を判定するスピーキングテスト。「95% CEFR English level accuracy」「150 万件以上のテスト実施」を謳う（ベンダー自身の主張で第三者検証は未確認）。（確度: 中）
- IELTS Speaking Simulator: IELTS スピーキング Part 1–3 を模擬し、推定バンドスコアを返す。（確度: 中）
- Mock Job Interview Practice: AI 面接官との模擬面接とフィードバック。（確度: 中）
- 日々の練習モード: スピーキング練習、シャドーイング、リスニング、クイズ。（確度: 中）
- Vocabulary Booster: 語彙強化ツール（詳細不明、確度: 低）。
- 構造化コース: ビジネス英語、日常会話、上級スピーキング、アカデミック英語のパス（詳細不明、確度: 低）。

## UI・UX の特徴とそれが嬉しい理由

- 特徴: マイク入力でブラウザから直接話しかけられる音声インターフェース。メインセッションの確認でも「speak into your mic」という記述を確認。
  - 嬉しい理由: 立ち止まって入力する手間がなく、実際の会話に近い形で瞬発的なスピーキングを試せると読める（ただし公式ページはこの効果を明言しておらず、調査側の推測が入っている点に注意）。
  - URL: https://smalltalk2.me/ / 確度: 中
- 特徴: ダッシュボードでの進捗トラッキングを「人間講師には見えない指標」と位置づけている。
  - 嬉しい理由: 数値化された継続記録がモチベーションになる、という訴求だが、実際の画面キャプチャや操作フローは未確認のため、この先の粒度（グラフか一覧か等）は分からない。
  - URL: https://smalltalk2.me/ / 確度: 中
- それ以外の UI・UX の具体的なメカニズム（フィードバック画面のレイアウト、ヒント表示のタイミング、レベル切り替えの UI など）は、公式サイトのトップページ・第三者記事のいずれからも確認できなかった。

## このアイデアへの示唆

- 借りられる仕組み: 「take a speaking test → receive feedback → select a learning path」という、CEFR 判定を起点に体験を分岐させる設計思想は参考になるが、本アイデアはレベルをユーザー自身が選ぶ設計であり、判定コストをかけない点で異なる。
- 避けるべき作り: 料金の不透明さ（複数の情報源が食い違う）はユーザー体験としても不信を招きやすい。本アイデアがログインなし・シンプルな課金（またはサーバーレス無料運用）を選ぶなら、この不透明さを避けられる。
- この製品が空けている場所: CEFR 判定を看板にしながら、判定後に何が変わるか（お題難度・添削の厳しさ・テンプレート支援）が公式にも第三者にも説明されていない。本アイデアの「レベルが言い直しの水準を変える」という明示的な設計は、ここで差別化できる可能性がある。
- 推奨であって決定ではない。決定は decisions.md へ。
