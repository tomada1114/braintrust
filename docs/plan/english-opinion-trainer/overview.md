# english-opinion-trainer

英語で「自分の意見を短く伝える」ことに特化した、ブラウザで動くチャット専用の反復ドリル。

## 誰の何の困りごとか

- 対象: オーナー自身。および、英語で自分から何かを言うことに慣れていない日本語話者一般（他者に同じ痛みがあるかは未確認、open-questions.md 参照）。
- 困りごと: 3 つの場面で観測済み。
  - (a) IELTS の Speaking / Writing の練習と本番で、問われたことにさっと意見が出せず詰まった。
  - (b) 対面で初対面の人と話す場面やディスカッションで、議題に対して黙ってしまった。
  - (c) そもそも意見自体が浮かばず、日本語でも言えなかった（英語の問題ではなく「タネ」の問題）。
- 本来の場面は対面・ディスカッションで、1〜2 文で答えることも多い。長文練習が目的ではない。
- IELTS は背景の一つに過ぎず、試験対策（Part 2 の独白や Writing）は対象外。

## 実在する痛みか

上記 3 場面はすべてオーナー自身の観測。頻度は未記録。いまの代替は ChatGPT 等に直接お題を出させる練習と、英会話レッスン・人との練習。それぞれの代替で我慢できていない理由は次節の通り。オーナー以外に同じ痛みがあるかは未確認（open-questions.md へ）。

## 既存プロダクトとの違い

競合調査は `research/competitors/_comparison.md`（2026-09-07、6 製品: Langua / スピフル / Practice Me / SmallTalk2Me / ChatGPT / LangJournal）。

- 既存: ChatGPT に直接お題を出させて練習する方法。オーナーの観測では、フィードバックの形式が使っているうちによく崩れ、安定しない。2 ターンの一次観察ではプロンプト 1 つで指定形式・CEFR レベル・日本語説明が維持されたが、サンプルが短く、オーナーの繰り返しの観測を覆す根拠にはならない。ほかの弱点は、新しいチャットのたびにセットアップが要る、履歴が白紙から始まる、添削後の文が構造化されて溜まらない、添削が甘い（第三者記事）。
- 既存: 英会話レッスン・人との練習。「一言で言う」「時間をもらって長く喋ろうとすると支離滅裂になる」という答え合わせは得られる。ただし場がないと練習できず、発言単位の形式的なフィードバックは得にくい。
- 既存: AI 英会話・添削アプリ（Langua、スピフル、SmallTalk2Me、LangJournal など）。音声会話か日記添削が中心。Langua は既定で添削が出ず（訂正モードが Off、レポートは発言 6 回以上）、スピフルは音声入力・ビジネス特化で 1 分語る形式。
- 差分（調査で「どの製品も未対応」と確認できたもの）: PREP などの構成テンプレート、意見のタネ（複数候補のヒント）、ユーザーが選んだ CEFR レベルで言い直しの水準が変わる、ログインなしでブラウザだけで即開始。全製品共通の未解決課題「ヒントがあっても何を言えばいいか分からない」に、タネ + テンプレートで当たる。
- 注意: 素の ChatGPT にプロンプト 1 つで 8 割は再現できる。守れる差分は運用面（即開始、言い回しリストが溜まる、お題の体系）であることを前提に立ち位置を決めた（decisions.md 2026-09-07）。

## 何を作るか（現時点の像）

- 形態: ブラウザで動くチャット専用アプリ。テキスト入力。
- 中核の体験: ランダムに出るお題に対して、ユーザーが英語で意見を書く。短文モード（1〜2 文、対面・ディスカッション想定）と長めモード（同じ問いに PREP で 4〜6 文でまとまって答える）の 2 モード。お題は日常の軽い問い（例: 今度日本に行くんだけどおすすめは？）。どちらも 5 分以内。意見が浮かばないときは複数候補のタネ（ヒント）を出せる。PREP などのテンプレートで組み立てを支える。回答 1 つに対してレベル（B1 など、ユーザーが選ぶ）に合わせた決まった形式のフィードバックが返る。
- 表記: UI は英語が既定。日本語に切り替えると UI とフィードバックが日本語になる。既に出力済みのフィードバックをその場で何度も言語切替させることはしない（LLM の無駄遣い）。
- 状態: ログインなし。レベル・表記言語・直近の履歴はブラウザ内保存。将来は外部システムで認証と DB を持てる構成にする。
- AI の位置づけ: LLM に任せるのはフィードバック生成と意見のタネ（ヒント）生成。お題は人手で作った固定リストからランダムに出す（LLM 不要）。テンプレートも固定。

## 最初の版で捨てるもの

- ログイン・サーバー側保存
- 日本語以外の多言語対応（将来したい）
- 出力済みフィードバックの言語再生成
- お題の LLM 生成
- 音声入出力（チャット専用と決めているため。ただし IELTS Speaking との関係は open-questions.md へ）

注: 両モードとも最初の版に入れる（decisions.md）。

## 作らない選択肢

作らなければ、ChatGPT に毎回場面と形式を指示して練習し続けることになる。それで我慢できなかったのがこのアイデアの起点。ただし、ChatGPT のカスタム指示や既存アプリで痛みの大半が消えるなら、作る理由は弱くなる。これは競合調査で確かめる。
