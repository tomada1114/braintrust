# 音声 — TTS / STT の選択肢

- 調査日: 2026-09-06
- 調査手段: Dynamic Workflow(Sonnet 調査 + Sonnet 検証 + Opus 執筆)
- 更新の目安: 3 ヶ月

選択肢は 4 カテゴリに分かれる。ブラウザ内蔵(Web Speech API)、OS 内蔵(macOS の say / AVSpeech)、ホスト型 API(OpenAI / Google Cloud / ElevenLabs / Deepgram)、ローカル OSS(whisper.cpp / Kokoro / Piper)。

## 選ぶときの軸

- **課金** — TTS は文字数課金(OpenAI・Google・ElevenLabs)とクレジット課金が混在し、STT は分課金が主流。リアルタイム音声対話はトークン課金で桁が変わる。
- **無料枠** — Google Cloud は恒久的な月次無料枠を持つ。Deepgram は期限なしの $200 クレジット。ブラウザ内蔵と OS 内蔵とローカル OSS は無料。
- **データ利用** — 音声は本人性の高いデータで、学習利用・保持期間・ZDR の扱いが重要になるが、今回の調査では各社のポリシーまで踏み込めていない(未調査)。
- **認証とサブスク転用の可否** — ホスト型はいずれも API キー方式で、個人向けサブスクの転用という論点は生じない。
- **構造化出力** — STT 側では単語レベルのタイムスタンプ・アライメントが相当する(未調査)。
- **SDK** — ブラウザ内蔵は Web API そのもの、ホスト型は各社 SDK、ローカル OSS は CLI / バインディング。
- **ロックイン** — ローカル OSS(whisper.cpp / Kokoro / Piper)は端末内で完結し乗り換え自由。ホスト型は音声の質と API 形状の両方で移行コストがかかる。

## ブラウザ内蔵(Web Speech API)

- `speechSynthesis`(音声合成)は Baseline "Widely available"(2018-09 以降)(https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis, 確認 2026-09-06, 確度 高)
- 個別ブラウザの対応開始バージョン(Chrome 33 / Edge 14)、IE・Opera Mobile・旧 Android 標準ブラウザの非対応、Firefox for Android の synthesis 欠落は、取得したページ抜粋に表示されず互換性表の別途参照が必要。**未確認**(https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis, 確認 2026-09-06, 確度 低)
- `speechSynthesis` は OS の TTS エンジンを呼ぶ実装が多く多くの場合オフラインで動くとされるが、iOS Safari では `speak()` がクリックハンドラ直下でないと発話しない等の制約がある。**未確認**(https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis, 確認 2026-09-06, 確度 低)
- `SpeechRecognition`(音声認識)は "Limited availability" で Baseline ではない。Chrome は既定でサーバーベースの認識エンジンを使い音声を外部 Web サービスへ送るため、オフラインでは動作しないと MDN が明記している(https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition, 確認 2026-09-06, 確度 高)
- オンデバイス処理向けに `processLocally`、`SpeechRecognition.install()`(言語パックのインストール)、`SpeechRecognition.available()`(オンデバイス可否の確認)が追加されている(https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition, 確認 2026-09-06, 確度 高)
- Safari が macOS 14.1+ / iOS 14.5+ で `webkitSpeechRecognition` をサポートし言語パック導入済みならオンデバイス認識できる、Firefox は `dom.webspeech.recognition.enable` フラグの裏で既定無効、という記述は第三者サイト由来。**未確認**(https://www.testmuai.com/learning-hub/speech-recognition-api-browser-support/, 確認 2026-09-06, 確度 低)

## OS 内蔵(macOS)

- `AVSpeechSynthesizer` は完全にオンデバイスで動作しネットワーク接続を要さない、コマンドラインの `say` も同じくローカルの音声エンジンを使う、とされる。**未確認**(WWDC セッションからの間接確認)(https://developer.apple.com/videos/play/wwdc2023/10033/, 確認 2026-09-06, 確度 低)

## OpenAI

- TTS: `tts-1` $15.00 / 100 万文字、`tts-1-hd` $30.00 / 100 万文字。`gpt-4o-mini-tts` はトークン課金でテキスト入力 $0.60、音声出力 $12.00 per 1M トークン(https://developers.openai.com/api/docs/pricing, 確認 2026-09-06, 確度 高)
- STT: `whisper-1` $0.006/分。`gpt-4o-transcribe` は入力 $2.50 / 出力 $10.00、`gpt-4o-mini-transcribe` は入力 $1.25 / 出力 $5.00 per 1M トークン(https://developers.openai.com/api/docs/pricing, 確認 2026-09-06, 確度 高)
- Realtime API の音声トークン: `gpt-realtime` と `gpt-realtime-2.1` はいずれも入力 $32.00 / 出力 $64.00(キャッシュ入力 $0.40)、`gpt-realtime-2.1-mini` は入力 $10.00 / 出力 $20.00(キャッシュ $0.30) per 1M トークン。リアルタイム音声対話は他の用途と桁が違う(https://developers.openai.com/api/docs/pricing, 確認 2026-09-06, 確度 高)
- 音声 API の無料枠について公式料金ページに明記はない(https://developers.openai.com/api/docs/pricing, 確認 2026-09-06, 確度 中)

## Google Cloud

- TTS の無料枠は Standard 音声が毎月 400 万文字、WaveNet 音声が毎月 100 万文字(恒久枠・期限なし)。有料は Standard/WaveNet $4、Neural2 $16、Chirp 3 HD $30、Studio 最大 $160 / 100 万文字。新規顧客には別途 $300 のクレジット(https://cloud.google.com/text-to-speech/pricing, 確認 2026-09-06, 確度 中)
- Instant Custom Voice $60 / 100 万文字は第三者情報源でも再確認できなかった。**未確認**(https://cloud.google.com/text-to-speech/pricing, 確認 2026-09-06, 確度 低)
- STT の無料枠は毎月 60 分の恒久枠。新規顧客は $300 クレジット(90 日)。有料は V1 標準 $0.006/15 秒(= $0.024/分)、V2 のリアルタイム標準が $0.016/分から量に応じて $0.010、$0.008/分まで下がる(https://cloud.google.com/speech-to-text/pricing, 確認 2026-09-06, 確度 中)
- V1 の拡張(enhanced、ログ非保存)$0.009/15 秒は今回の情報源では再確認できなかった。**未確認**(https://cloud.google.com/speech-to-text/pricing, 確認 2026-09-06, 確度 低)
- なお Google Cloud の料金ページは本調査環境から直接取得できず、複数の第三者集計を突き合わせている。無料枠の存在と料金レンジは一致しているが、細部は原典での再確認が要る。

## ローカル OSS

- whisper.cpp は MIT。モデル別のディスク/メモリは tiny 75MiB / 約 273MB、base 142MiB / 約 388MB、small 466MiB / 約 852MB、medium 1.5GiB / 約 2.1GB、large 2.9GiB / 約 3.9GB。Apple Silicon(NEON / Accelerate / Metal / Core ML)、NVIDIA、AMD ROCm、Vulkan に対応し、macOS / iOS / Android / Linux / Windows / Raspberry Pi / WebAssembly / Docker で動く(https://github.com/ggml-org/whisper.cpp, 確認 2026-09-06, 確度 高)
- 4bit 量子化で large-v3 を 1.5GB → 380MB に縮小できる(WER 増は約 1%)、small が WER 約 3.4%・RAM 約 2GB、medium が WER 約 2.9%・RAM 約 5GB、実用レイテンシは発話から 0.5〜2 秒、といった数値は第三者ベンチマーク由来で公式リポジトリ本文にはない。**未確認**(https://github.com/ggml-org/whisper.cpp, 確認 2026-09-06, 確度 低)
- Kokoro-82M は 8200 万パラメータの軽量オープンウェイト TTS で Apache-2.0。米英西仏印伊日ポ中など複数言語・複数音声に対応し、GPU 不要で CPU のみでも動作する。音素処理に espeak-ng を要する(https://github.com/hexgrad/kokoro, 確認 2026-09-06, 確度 中)
- Piper は元の rhasspy/piper(MIT)がアーカイブされ、Open Home Foundation 配下の OHF-Voice/piper1-gpl(GPL-3.0)へ開発が移った。Raspberry Pi 4 での動作を意識した最適化がある(https://github.com/OHF-Voice/piper1-gpl, 確認 2026-09-06, 確度 中)
- アーカイブ日を 2025-10 とする記述は GitHub API から確認できず、最終 push は 2025-08-26 だった。各音声モデルに MODEL_CARD で個別ライセンスが付くという記述もトップページの取得範囲では確認できていない。**未確認**(https://github.com/OHF-Voice/piper1-gpl, 確認 2026-09-06, 確度 低)

## グレーゾーン・未確認

- OpenAI の音声 API に無料枠が現在あるかは公式料金ページから判断できない。新規登録クレジットの施策は変動するため都度確認が要る。
- Google Cloud の TTS / STT 料金ページは本調査環境から直接取得できず、第三者集計の突き合わせにとどまる。Studio 音声の上限価格と V2 の量的割引段階は原典での再確認が望ましい。
- whisper.cpp の WER・リアルタイムファクター・体感レイテンシ、Piper の音声品質と Raspberry Pi 実測性能は、公式リポジトリのトップページに定量データがない。
- Kokoro のサポート言語・音声数はバージョン間で変動しており(v0.19 → v1.0)、最新リストは Hugging Face の README での再確認が要る。
- macOS の say / AVSpeechSynthesizer のプロソディの自然さや速度調整の実用性について、Apple 公式に定量的・比較的な記述は見当たらない。ブラウザ内蔵 `speechSynthesis` の声質も OS / ブラウザ実装ごとに大きく異なり、一律に評価する公式指標は存在しない。
- 検証で落とした記述: `gpt-realtime` の音声出力を $16.00 / 1M トークンとしていたもの(正しくは $64.00 で、`gpt-realtime-2.1` と同額)。Piper のアーカイブ日「2025 年 10 月」。
- 今回の調査が触れていない論点: 各社の音声データの学習利用可否・保持期間・ZDR の有無、ストリーミング対応の実装詳細とレイテンシ実測、ファイルサイズ・長さ上限とレート制限(Whisper 系の 25MB 制限など)、単語レベルのタイムスタンプ / アライメント対応、SSML・IPA 指定・速度/ピッチ制御、英語アクセント(米/英/豪)の選択肢、モデルをアプリにバンドルした場合の配布サイズとストア審査、Kokoro / Piper の個別音声モデルの商用可否、データレジデンシーと GDPR、想定利用量に基づく月額試算、2026 年時点のブラウザ/OS ごとの詳細対応表、複数話者によるダイアログ生成。
